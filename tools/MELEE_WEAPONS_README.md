# Выгрузка оружия ближнего боя с fallout-2d20.ru

Дата: 2026-09-25  
Источник: https://www.fallout-2d20.ru/oruzhie/oruzhie-blizhnego-boya (38 страниц)  
Язык: ru-RU, система Fallout 2D20

## Что сделано

По твоему списку ссылок (Выкидной нож, Дубинка, Меч ... Сварочная горелка — 38 штук) полностью выгружены все страницы, распарсены таблицы и собраны JSON.

### Глоссарий «что делают»

Вынесен в `glossary`. Кратко:

* **Проникающий X** — игнор X СУ за каждый выпавший Эффект (у перфоратора 2, у горелки 3)
* **Порочный** — +1 урон за каждый Эффект
* **Устойчивый / Стойкий** — `Persistent` (эффект урона сохраняется)
* **Оглушающий / Оглушение** — `Stun` (шанс оглушить)
* **Разрушающий** — `Breaking` (ломает броню)
* **Скрытное** — `Concealed` (легко прятать)
* **Парирование** — `Parry` (можно парировать, + защита)
* **Двуручное** — `Two-handed` (одной рукой +2 сложности)
* **Ослабляющее / Изнуряющий** — `Debilitating`
* **Неточный** — `Inaccurate` (+1 сложности)
* **Топливо** — `Fuel` (требует 4 топлива для огнемета, при Осложнении кончается)
* **Отдача X** — `Recoil X` (если СИЛ < X, +1 сложности; игнорируется двумя руками)
* **Медленная перезарядка** — `Slow Load` (малое действие на перезарядку)
* **Всплеск** — `Blast` (урон по зоне)

Плюс `specialRules` для уникальных механик: Баллистический кулак (жрёт патрон дробовика), Бензопила (без бонуса СИЛ), Танбо/Барабан/Гитара (+1 к Осложнениям в скрыте из-за шума), Перфоратор (тратит 1-3 заряда Ядерной батареи → +1-3 КК), Автотопор Турбо (1 ОД = +2 КК) и т.д.

### Моды: 63 установки, 50 уникальных

26 оружий имеют моды (от 1 до 5 на пушку), 12 без модов (чистые уникалки).  
Примеры:

* **Выкидной нож — Зазубренное лезвие (Кузнец 1):** `+1 КК + Устойчивый`
* **Дубинка — Электризованная (Кузнец 2 + Наука 1):** `+2 КК, смена на Энергетический`; **Электрошокер:** `+3 КК + Оглушающий + Энергетический`
* **Меч — 4 варианта:** от просто `Устойчивый` до `+2 КК + Оглушающий + Энергетический`
* **Бейсбольная бита — 5 вариантов:** от бесплатного `Проникающий` до топового `+2 КК + Устойчивый` (Клинковая)
* **Бензопила — 4 шины:** Двойная (`+2 КК`), Изогнутая (`Проникающий`), Удлинённая изогнутая (`Стойкий`), Огнемет (`+1 КК + Энергетический`, единственный стакующийся с другими)
* **Посох Атома — Шокирующие катушки (Кузнец 2 + Наука 2):** `+2 КК, наносит Физический + Энергетический одновременно`

Вес/цена в таблице сайта указаны как дельта (`+1`, `+100`) или `-` (без изменения) — в JSON продублированы как число и как raw-строка.

### Как обновить приложение

Если хочешь чтобы новые 16 пушек появились в Companion:

1. Скопируй объекты из `tools/melee_companion_import_example.json → weapons_import` в `modules/fallout/data/equipment/weapons.json`
2. Скопируй `mods_import` в `modules/fallout/data/equipment/weapon_mods.json`
3. Добавь переводы из `i18n_ru_import.weapons/weaponMods` в `modules/fallout/i18n/ru-RU/data/equipment/weapons/weapons.json` и `weapon_mods.json` (и аналогично в `en-EN` — переведи `name`)
4. (опционально) заявки на слоты уже `Unique`, дополнительных правок `weapon_mod_slots.json` не нужно — но можно добавить явные записи для наглядности (пример в `slots_example`).

После этого `getEquipmentCatalog()` автоматически подхватит новые данные.

### Автоматизация

Прямой `curl`/`fetch` с этого хоста к `fallout-2d20.ru` сейчас режется по TLS (проверено `ECONNRESET`), поэтому выгрузка делалась через прокси-инструмент `fetch_page`. Для повторной выгрузки можно скопировать паттерн из этого README и прогнать через `fetch_page` или использовать сохранённые HTML из `tools/` как кэш.

### Проверка

```bash
python3 -m json.tool tools/melee_weapons_fallout2d20_ru.json > /dev/null && echo OK
python3 -m json.tool tools/melee_companion_import_example.json > /dev/null && echo OK
```

Оба файла — валидный JSON. Количество записей проверено: 38 оружий, 63 вложенных модов, 50 уникальных.
