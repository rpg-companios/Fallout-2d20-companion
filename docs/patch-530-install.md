# Установка патча 530: взлом локации = вход, взлом контейнера = содержимое

Патч подготовлен от состояния **версии 529** (коммит `45fa59f`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–530
цепочкой. Файл установки: `patchs/530-hack-outcome.patch`.

Это первый из четырёх остававшихся пунктов тезиса 13 «Иерархия пространств и
доступ». Закон снимка 529 (`docs/gm-snapshot-law.md`) обязателен и для этого
патча, и для всех следующих.

## Что изменено

### 1. Канон семантики

Новый `components/lootTrade/hackOutcome.js` — чистые функции без React и сети:
`nodeHasChildren()`, `hackOutcomeForNode()` (`enter` / `contents`),
`applyHackOutcome()` (ровно один адресный переход, без каскада),
`hackWinKey()` (дедупликация победы), `HACK_OUTCOME_DELAY_MS = 700`.
Узел с `childIds` (или `kind: hub` у старых сессий) — локация; без детей —
контейнер.

### 2. Интерфейс `PlayerLootTradeOverlay.js`

- Один `navigateHackOutcome()` на три пути: обычная кнопка узла, кнопка после
  выигранной проверки, автоматический исход ACCESS GRANTED.
- Подсказка `hack-outcome-hint-*` у запертых точек и точек-источников:
  «Взлом откроет вход в локацию» / «Взлом откроет содержимое».
- Подписи кнопок: «Взломать и войти» / «Взломать и открыть» (у ворот — по
  целевому узлу); обычная кнопка вложенной локации — «Войти».
- У выигранной точки-замка/локации — `hack-outcome-button-*` («Войти» /
  «Открыть»), чтобы доступ к содержимому не терялся после закрытия мини-игры.
  Чистый терминал без детей такую кнопку не получает.
- Парные RU/EN строки в `i18n/*/screens/lootTrade/screen.json`.

### 3. Автоматический исход победы

ACCESS GRANTED на явно нажатом «Взломать» (`autoStart`) внутри настоящей
локации через 700 мс закрывает мини-игру и применяет исход по `targetNodeId`:
`enter` → `parentStack`, `contents` → `selectedHubNodeId`. Срабатывает один раз
на `(containerId, accessId, revision)`; «Смотреть», отдельно выданная точка и
повторное открытие выигранной доски навигацию не дёргают. Это переход, а не
рестарт: доска после победы не пересобирается (505/526), игрок сам решает,
сколько подходов делать.

## Что сохранено

Сервер **не менялся**: закон снимка 529 (`char.command` → `char.refresh` →
`char.publish`, снимок как наблюдение между сессиями), защита сообщений/ролей,
граница видимости и адресный взлом 523, общие ресурсы привязанных комнат и
одна сессия, канон «Заколка» 527, пауза перед сбросом красного 528,
светлая гамма 525, четыре попытки терминала и `shouldBlockLock()`.

обновить PWA-кэш: имя бандла изменилось.
