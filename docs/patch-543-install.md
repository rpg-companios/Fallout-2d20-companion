# Установка патча 543: перекрытие проходов

Патч подготовлен от состояния **версии 542**. Файл установки:
`patchs/543-passage-block.patch`.

> Владелец (модель тезиса 28): в цепи А–Б–В блок Б = нельзя войти в Б ни из
> А, ни из В (транзит через Б обрывается); исключение — обходной путь
> («только если в В нет выхода А»): если есть выход В→А или любая цепь не
> через Б, А↔В остаются связанными, автопереходов/пересчёта нет. Мастер
> указывает причину свободным текстом; если не указано — «Проход заблокирован»
> / EN «Passage blocked». Данные — пара полей на самой локации, без новых
> сущностей и списков рёбер. UI Мастера: в строке названия локации, рядом с
> кнопкой параметров, перед ней, кнопка надписью «Блокировать»; при блоке —
> «Открыть». UI игрока: экран-дверь по образцу привратника 542 (имя, причина,
> «Назад», без кнопок взлома) и плашка с причиной в списке. Глухая преграда
> сильнее замка — снимает только Мастер.

## Границы

- Блокируется сама локация-узел: запрещён вход в неё со всех сторон
  (ребро/направление не хранятся); выход из заблокированного узла разрешён —
  правило запрещает вход, не выход.
- Обходные пути не пересчитываются: другой родитель или выход в обход блока
  продолжают работать; автопереходов и пересчёта графа нет.
- Прямая выдача Мастера — не вход: корень выдачи блок не ломает (иначе
  выданная локация была бы пустым экраном).
- Замок при блоке не предлагается (глухая преграда сильнее), но механика
  замков/терминалов, закон снимка 529 и канон 542 не менялись.
- Автоправила (обвал по времени, направленность, «выхода назад нет»), карта
  и экспорт Owlbear — задел по слову владельца, в этом патче нет.
- `apply-patch.sh` смотрит на ту же ветку доставки
  `arena/aa289f1c-fallout-2d20-companion`.

## Установка через консоль

Из корня репозитория приложения: сначала заменить `apply-patch.sh` свежей
версией из ветки доставки, затем поставить патч 543.

```bash
git fetch --no-tags origin arena/aa289f1c-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 543
```

## Проверки

- `npm test`: зелёные, кроме восьми заранее известных падений
  `__tests__/room/terminal-hacking-balance-496.test.js` — они падают теми же

## Откат

`git apply -R patchs/543-passage-block.patch` вернёт поля прохода, кнопку,
диалог, дверь, словари и версию к состоянию 542.
