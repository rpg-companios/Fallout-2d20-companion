## Что меняется

Скобочная пара теперь **и есть подсказка**. Отдельных «бесплатных проверок
сходства» нет: сходство `N/M` можно узнать только одним способом — ткнуть
слово и потратить попытку. Скобки дают три эффекта: удалить пустышку,
`+1` попытку или полный сброс.

| Величина | Формула |
|---|---|
| Число слов `N` | `max(Мин_N[d], База_N[d] − (ИНТ − 4))`, базы `8/10/12/14/17/20`, полы `4/5/6/7/9/10` |
| Попытки `T` | `4 − floor(d / 3)` → 4 на `d0..d2`, 3 на `d3..d5` |
| Скобочные пары `P` | `max(0, min(1 + floor(Наука/2) − floor(d/3), 3, N − 3))` |
| Эффект пары | броском `d20` по УДЧ: `1..F` — полный сброс, `F+1..P` — `+1` попытка, остальное — удаление пустышки |

Границы `d20` по УДЧ 4…10: `[1,5] [1,6] [2,7] [2,9] [3,10] [3,12] [4,15]`.
Полный сброс срабатывает **только один раз за терминал**; повторный результат
«сброс» считается как `+1` попытка. Очки удачи при взломе не расходуются.

Предел позиционных совпадений оставлен из 495 (`3/3/3/2/2/2`): именно два
совпадения на сложности 5 дают думающему игроку 80 %+, а бездумному перебору —
около четверти. Доска собирается из трёх буквенных групп (похожие /
смешанные / непохожие), без кластеров с общим двухбуквенным префиксом;
пароль больше не является «самым центральным» словом доски.

### Замеры на реальном движке (24–40 досок на сценарий)

| Сценарий, сложность 5 | Слов | Попыток | Пар | Бездумный перебор | Вдумчивый разбор | При полном сбросе |
|---|---|---|---|---|---|---|
| ИНТ 4 / Наука 0 / УДЧ 4 | 20 | 3 | 0 | 20 % | 65 % | — |
| ИНТ 10 / Наука 3 / УДЧ 4 (старт) | 14 | 3 | 1 | 35 % | **85 %** | **100 %** |
| ИНТ 8 / Наука 4 / УДЧ 6 | 16 | 3 | 2 | 35 % | 90 % | 100 % |
| ИНТ 10 / Наука 6 / УДЧ 10 | 14 | 3 | 3 | 53 % | 100 % | 100 % |

Сложности 0–2 остаются лёгкими по замыслу владельца: «на 1-й сложности пара
попыток и подсказка — всё решил», на 0 — «просто найти непохожее слово».
Хакер снижает эффективную сложность на 1 за ранг (минимум 0), и это теперь
видно в окне взлома строкой «Хакер: сложность 1 → 0».

## Через `apply-patch.sh` (основной способ)

```bash
./apply-patch.sh 496
```

Если вы всё ещё на `a62ec71` со старым установщиком
(`arena/c1c60b87-fallout-2d20-companion`), один раз переключите источник:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 496
```

`./apply-patch.sh --status` до установки может написать «Всё актуально»:
ориентируйтесь на `public/version.json` и явно указывайте номер патча.
`patchs/baseline.json` в ветке-источнике равен `496`, поэтому при установке
точно до отсечки дерево приводится к коммиту патча целиком, а каталог
`patchs/` синхронизируется (файл `patchs/496-terminal-hacking-balance.patch`
появится и локально).

После установки:

- `public/version.json` → `496`, `patchs/baseline.json` → `496`;
- закоммитьте изменения (`git add -A && git commit -m "Патч 496"`);
- **перезапустите сервис Node.js** (`server/`): общие доски комнат создаются
  сервером, локальный резерв на клиенте работает сразу.

### Прямой `git apply` без установщика

Патч-файл не может содержать сам себя, поэтому при ручном наложении его нужно
скопировать в `patchs/` отдельно:

```bash
git apply patchs/496-terminal-hacking-balance.patch
cp /path/to/496-terminal-hacking-balance.patch patchs/
```
