## Через `apply-patch.sh`

В коммите `a62ec71` установщик берёт цепочку патчей из ветки
`arena/c1c60b87-fallout-2d20-companion`. Патч 493 лежит в ветке
`arena/054e6676-fallout-2d20-companion`, поэтому один раз нужно переключить
источник:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 495
```

`patchs/baseline.json` в ветке-источнике равен `495`, поэтому установщик работает
в режиме отсечки: за один шаг он приводит всё дерево к состоянию коммита,
в котором добавлен `patchs/493-terminal-hacking-on-main-491.patch`. Никакие
промежуточные патчи поверх не накладываются, а файлы «Окружающая среда/бой»
(патчи 482–486) не удаляются — базовое дерево `a62ec71` взято целиком.
Вместе с деревом синхронизируется и сам каталог `patchs/`: локальный
`baseline.json` становится `493`, файл патча 493 появляется на диске.

`./apply-patch.sh --status` до установки может написать «Всё актуально»: старые
патчи из цепочки уже перекрыты содержимым `a62ec71`. Ориентируйтесь на версию в
`public/version.json` (`491`) и просто запускайте `./apply-patch.sh 495`.

После установки:

- `public/version.json` → `493`;
- `apply-patch.sh` уже указывает на новую ветку (приходит вместе с деревом),
  поэтому следующие обновления ставятся просто `./apply-patch.sh <номер>`;
- не забудьте закоммитить изменения (`git add -A && git commit -m "Патч 493"`);
- **перезапустите сервис Node.js** (`server/`), чтобы сервер комнат начал
  отдавать `capabilities.terminalHacking` и доска взлома стала общей для всех
  игроков. Без перезапуска мини-игра всё равно открывается и работает локально
  на устройстве игрока (в окне есть подсказка).

## Без `apply-patch.sh`

Если установщик недоступен, патч — обычный `git`-дифф:

```bash
git apply --check patchs/493-terminal-hacking-on-main-491.patch
git apply patchs/493-terminal-hacking-on-main-491.patch
```

## Что именно чинится

Сервер комнат старой версии при выдаче локации пересобирает узлы и понижает
`kind: 'terminal'` до `'loot'`, теряя `difficulty` и `lockOnFailure`, — игрок
видел сундук. Конфигурация терминала теперь дублируется маркером в `lockLabel`
(поле сохраняется даже старым сервером), клиент восстанавливает из него тип
узла и открывает `TerminalHackingModal`. При отсутствии
`capabilities.terminalHacking` та же мини-игра запускается локально.
