# Установка патча 547: сигнал об успешном взломе

Патч подготовлен от состояния **версии 546**. Файл установки:
`patchs/547-hack-success-signal.patch`.

> Баг владельца: «я взломал замок, модалка взлома предложила ещё попытку —
> "успешные попытки" не должны вызывать ещё попытку. Из-за того, что модалка
> взлома не передала данные о взломе, я не могу пройти дальше. Тоже самое с
> терминалом должно быть — показан, успех, кнопка закрыть — передача сигнала
> об успешном взломе — доступ к содержимому».

## Границы

- Победа оконечна. Новую партию начинает только Мастер: «Открыть» или повторная
  выдача точки (доска снимается, следующий подход собирается по свежему листу).
- «Ещё подход» сохранён там, где он нужен: провал, «кончились заколки»,
  закрытая доска — правило 526 не отменено.
- Закон снимка 529 не тронут: сервер не правит лист игрока.
- Адресный взлом 523 сохранён: сигнал открывает ровно свою цель, каскада нет.
- Сетевой автопереход 530 (пауза перед входом по реестру комнаты) сохранён;
  в локальном резерве исход применяет кнопка «Закрыть».
- Журнал `localCheckAccess` — только резерв. У комнаты с протоколом мини-игр
  источником истины остаётся сервер и его общий журнал `accessEvents`.

## Установка через консоль

```bash
git fetch --no-tags origin arena/f90c80d8-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 547
```

После установки обновите лёгкий сервер комнат (`deploy-netangels.sh`): отказ
`LOCK_ALREADY_WON` живёт в `server/`. Клиентская часть работает и со старым
сервером — сигнал победы и журнал локального резерва полностью клиентские.
