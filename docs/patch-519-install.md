# Установка патча 519: терминал как замок сундука

Патч подготовлен от состояния **версии 518** (коммит `d6a3dc2`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–519
цепочкой.

> Владелец: «Я создал локацию, положил в неё сундук, в сундуке выбрал
> терминал, задал сложность. Выдано игрокам. В локации они видят и сундук и
> терминал. Открывают сундук берут добычу. Терминал не у дел. А должно быть,
> терминал не видно, а при попытке открыть сундук открывается терминал».

## Что исправлено

### 1. Привязанный терминал скрыт

`server/lootTradeSession.js`: при нормализации узлов локации терминал, на
который ссылается другая точка через вторую строку («Ворота: событие другой
точки»), получает признак `hiddenForPlayers`. Для игроков такой узел
убирается из списка; Мастер видит все карточки. Сервер по-прежнему создаёт
состояние мини-игры для скрытого терминала — иначе нечего было бы взламывать.

### 2. Нажатие на сундук открывает терминал

`components/lootTrade/PlayerLootTradeOverlay.js`: у запертой точки с воротами
вместо бейджа «Заперто» появляются кнопки «Смотреть» и «Взломать». Они
открывают мини-игру именно привязанного терминала (по его состоянию в
комнате), с той же одноразовой трансляцией и теми же правилами, что у обычного
терминала.

### 3. Добыча — только после проверки

Пока терминал не взломан, узел заперт, содержимое игрокам не передаётся и
взятие добычи отклоняется. После победы событие доступа (патчи 516–517)
открывает сундук сам. Найденный ключ открывает сразу, без мини-игры. Если
ключ объявлен **обязательным**, кнопок взлома нет — взлом не обходит
обязательное требование.

## Установка

С действующей версии 518:

```bash
./apply-patch.sh 519
# ✓ Установлен патч: №519 (версия 518 → 519)
```

С чистого `main` со старым установщиком:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 519
```

`patchs/baseline.json` в источнике равен `519`. После установки
`public/version.json` → `519`; закоммитьте изменения, **перезапустите сервис
Node.js** (серверный код менялся) и пересоберите веб-сборку.

## Проверка

```bash
npm run typecheck
npx vitest run __tests__/room/gate-terminal-519.test.js
npx vitest run
CI=1 EXPO_NO_TELEMETRY=1 NODE_ENV=production npm run build
curl -s http://localhost:5000/version.json | grep '"version": "519"'
```

Тесты покрывают пометку скрытого терминала, разницу вида у игрока и Мастера,
скрытие содержимого до взлома, отказ во взятии добычи и открытие после победы.
