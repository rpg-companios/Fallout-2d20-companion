# Установка патча 536: взлом замка — «Правила» и «Сведения» один под другим

Патч подготовлен от состояния **версии 535** (коммит `4fba7f1`, ветка
`arena/054e6676-fallout-2d20-companion`). Файл установки:
`patchs/536-lock-status-blocks.patch`.

> Владелец: «ветка ушла сильно вперед… В модалке взлома замка… Я так понял
> они занимают одну строку, но два контейнера. Можем переделать их под 2
> разных контейнера один под другим. 1й Правила, 2й сведения». Меняется
> только раскладка строки статуса; текст подсказки и механика не тронуты.

## Что меняется

| Слой | Что сделано |
| --- | --- |
| `components/lootTrade/LockPickingModal.js` | строка статуса `statusRow` заменена вертикальной колонкой `statusColumn`: счётчик заколок сверху, блок «Правила» (`lock-rules-block`), блок «Сведения» (`lock-info-block`) |
| `components/lootTrade/lockPickingStyles.js` | удалены `statusRow`/`statusLeft`; добавлены `statusColumn`, `rulesBlock`, `infoBlock`, `blockTitle`, `infoSkillLabel`; перенос описания сохранён |
| RU/EN словари `screens/lootTrade/screen.json` | парные `lock.rulesTitle` («Правила»/Rules) и `lock.infoTitle` («Сведения»/Details) |
| `__tests__/lootTrade/lock-status-blocks-536.test.js` | приёмочный тест двух вертикальных блоков |
| `__tests__/lootTrade/lock-arrows-legacy-531.test.js`, `__tests__/room/lock-progress-532.test.js` | исторические проверки переноса обновлены под `rulesBlock` |

Правила: счётчик заколок остаётся сверху заметным; контейнер 1 «Правила»
содержит описание мини-игры, контейнер 2 «Сведения» — сложность, LOCKPICK и
навык/восприятие/удачу. Рамка блоков повторяет ближайший образец модалок
(`docs/ui-modals-rules.md`), палитра `ADMIN_MODAL_PALETTE`, без литералов.
Закон переноса описания 531/534 сохранён. Механика взлома, память позиций 532,
«Мастер решает» 535 и панель заблокированной точки не тронуты. Терминальный
`statusRow` (другая модалка) не менялся.
