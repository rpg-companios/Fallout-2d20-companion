## Как это выглядит

1. Игрок на списке персонажей: никаких окон. У карточки, кому пришло, **синяя**
   иконка сервера (зелёная — в сети, серая — не в сети).
2. Игрок вошёл в этого персонажа — окно «Что прислал Мастер» в стиле
   «Что нового»: строки вида «Пайпер: +1 уровень (ур. 3) — Тапхаус».
3. «Понятно» закрывает окно и гасит синюю иконку.
4. Локация или торговец открываются плашкой ровно как раньше — ничего не
   изменилось по сравнению с версией до 558.
5. У Мастера в панели комнаты — «Отправлено: N».
6. Ключи и склад — как после 557.

## Установка через консоль

```bash
git fetch --no-tags origin arena/a97ebb5a-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 559
```

После установки: `git add -A && git commit -m "Патч 559"`.
