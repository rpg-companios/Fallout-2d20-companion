## Что зафиксировано

Полный контракт — `docs/key-items-and-gates-design.md`, **Обновление 7**

### 1. Вложенность и выдача

| Объект | Выдаётся напрямую | Внутрь локации | Содержит ключ | Требует ключ |
| --- | --- | --- | --- | --- |
| Локация | да | — | да | да |
| Контейнер | да | да | да | да |
| Торговец | да | да | да | да |
| Терминал | да | да | **нет** | да |
| Ключ / записка | **нет** | да | — | — |
| «Замок» (будущий) | да | да | **нет** | да |

Ключ как игровой объект попадает к партии только как содержимое выданной
локации, контейнера или торговца. В терминал не вкладывается.

**Исключение обратной совместимости:** пункт «Выдать на склад» в меню `⋮`
карточки ключа **остаётся** — прямое решение владельца «для backward
совместимости». Не удалять пункт, не ломать `storage.addKey`, не убирать
`kind: 'keyItem'` из снимка хранилища.

### 2. Перетаскивание

Все четыре карточки — контейнер, торговец, терминал, ключ — переносятся внутрь
локации, у каждой иконка со стрелками (`arrow-all`). Уже добытые записи при
переносе не изменяются.

### 3. Два вида требования и две строки настройки

Контейнер, торговец, терминал и будущий «замок» могут требовать ключ как
**обязательный** или **необязательный**. В карточке точки две строки:

1. ключ — поиск по названию или выбор из списка; рядом поле «Обязателен?»;
2. проверка — поиск или выбор из списка терминала / замка (будущей мини-игры).

Логика доступа:

- ключ есть на общем складе → мини-игра не запускается, точка открыта сразу,
  уведомления Мастеру нет;
- ключа нет и он обязателен → доступа нет (нужно добыть ключ или решение
  Мастера);
- ключа нет и он необязателен → проходят привязанный терминал / взлом /
  отмычку / силу, либо Мастер открывает вручную;
- проверка на сервере по идентификатору записи; текст записки для игроков не
  разбирается.

Примеры: сейф «ключом или взломом», сейф «только ключом», торговец
контрабандой с меткой фракции или компрометирующей запиской.

## Установка

С действующей версии 512:

```bash
./apply-patch.sh 513
# ✓ Установлен патч: №513 (версия 512 → 513)
```

С чистого `main` со старым установщиком:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 513
```

`patchs/baseline.json` в источнике равен `513`. После установки
`public/version.json` → `513`; закоммитьте изменения и пересоберите веб-сборку
(сервис Node.js перезапускать не обязательно — серверный код не менялся).
