## 2. Целевое состояние

### 2.1 Расположение и размер

Ячейку «Эффекты» вынести из второго ряда сетки и разместить ниже блока «Основные характеристики» — отдельной строкой на всю ширину экрана, на одном уровне с другими полноширинными элементами.

```
[ Инициатива ] [   Защита   ] [ Рукопашный бонус ]
[ Сопр. яду  ] [  Радиация  ] [     Здоровье     ]
──────────────────────────────────────────────────
  Эффекты                                      [+]
──────────────────────────────────────────────────
  (содержимое — видно при раскрытии)
──────────────────────────────────────────────────
```

> Ячейка «Эффекты» покидает сетку. Освободившийся слот занимает новая ячейка «Радиация».  
> Второй ряд сетки: «Сопр. яду» — «Радиация» — «Здоровье».

### 2.2 Поведение

| Свойство | Описание |
|---|---|
| **Ширина** | 100% контейнера (как у всех полноширинных блоков экрана) |
| **Высота** | Динамическая: подстраивается под количество строк с эффектами |
| **Заголовочная строка** | Слева — надпись «Эффекты», справа — иконка «+» |
| **Иконка «+»** | Toggle: открыть / закрыть содержимое спойлера |
| **Состояние по умолчанию** | Свёрнуто (collapsed) |
| **Анимация** | Плавное раскрытие (`LayoutAnimation` или `Animated`) — по возможности |

### 2.3 Структура заголовочной строки

```
┌────────────────────────────────────────┐
│  Эффекты                            +  │
└────────────────────────────────────────┘
```

- Левая часть: текст «Эффекты» (стиль `sectionTitle`)  
- Правая часть: TouchableOpacity с иконкой `Ionicons` — `add-circle-outline` (открыто) / `remove-circle-outline` (закрыто)  
- Иконка реагирует на нажатие в любой точке заголовочной строки (всю строку сделать нажимаемой)

### 2.4 Содержимое спойлера

Каждая строка — отдельный эффект:

```
  • [Иконка источника]  Название эффекта          (осталось: N сцен / постоянно)
```

Поддерживаемые источники эффектов (агрегируются в одном месте):

| Источник | Примеры |
|---|---|
| **Черты персонажа** | Радиационное исцеление, Иммунитет к яду |
| **Перки** | Бонусы атрибутов, боевые модификаторы |
| **Качества оружия** | Тихий, Точный, Бронебойный |
| **Эффекты оружия** | Bleeding, Burning, Knockdown |
| **Эффекты брони** | Stealth Field, Power Armor bonuses |
| **Моды оружия / брони** | Silencer, Night Vision |
| **Препараты / химикаты** | Stimpak, Med-X, Jet, Buffout |
| **Еда и напитки** | Nuka-Cola, Brahmin Steak |
| **Временные тimed-эффекты** | Любые с `timeRemaining > 0` |

Постоянные эффекты (от черт и перков) помечаются символом `∞` вместо таймера.

## 3. Ячейка «Радиация» — спецификация

### 3.1 Дизайн

Ячейка визуально идентична «Здоровью» (`HealthCounter`): компонент `StatBox` с двустрочным отображением значения.

```
┌─────────────────┐    ┌─────────────────┐
│   Здоровье      │    │   Радиация      │
│    12 / 20      │    │      7          │
└─────────────────┘    └─────────────────┘
```

- Значение радиации — целое число ≥ 0
- Отображается одним числом (текущий уровень радиации без знаменателя)
- Цветовая индикация (опционально, обсудить при реализации):
  - 0 — нейтральный цвет
  - 1–(maxHP/2) — жёлтый
  - > maxHP/2 — красный / мигание

### 3.2 Влияние на Здоровье

Радиация изменяет знаменатель в отображении Здоровья. Приложение не вводит понятие «эффективный максимум» и **не принудительно ограничивает** текущее ОЗ сверху — живой персонаж или нет, есть ли у него штрафы, решается за рамками приложения (IRL).

| Радиация | Отображение Здоровья |
|---|---|
| 0 | `currentHP / maxHP` |
| n | `currentHP / (maxHP − n)` |

Знаменатель может уйти в 0 или отрицательные значения — приложение отобразит как есть.

**Правила текущего ОЗ при наличии радиации:**

| Ситуация | Поведение |
|---|---|
| Было `20/20`, добавили радиацию 5 | Показывает `20/15` — currentHP **остаётся** на месте |
| Попытка вылечиться препаратом при `20/15` | Лечение **заблокировано** — нельзя поднять HP выше `(maxHP − radiation)` |
| Попытка вылечиться при `10/15` | Лечение работает, потолок — `15` |

> Приложение не убивает персонажа автоматически, не навязывает штрафы и не блокирует интерфейс — все нарративные последствия на усмотрение Мастера и игрока.

```js
// Псевдокод для HealthCounter
const displayMax = baseMaxHP - radiationLevel; // может быть ≤ 0, отображаем как есть
const healingCap = displayMax;                 // потолок при лечении едой/препаратами

// При применении лечащего предмета:
const newHP = Math.min(currentHP + healAmount, healingCap);
// Если currentHP уже выше healingCap — не трогаем (оставляем как есть)
const safeNewHP = currentHP >= healingCap ? currentHP : newHP;
```

### 3.3 Хранение и стейт

- Добавить поле `radiation: number` в стейт персонажа (Zustand store / SQLite schema)
- Начальное значение: `0`
- Хранится как обычная характеристика — не тimed-эффект

### 3.4 Изменение значения

Радиация меняется двумя способами — оба должны быть реализованы:

**Ручное управление** — кнопки `+` / `−` на ячейке (как у счётчика HP). Минимум — 0.

**Автоматическое изменение** — через систему применения предметов (еда, напитки, препараты):

| Источник | Направление | Механика |
|---|---|---|
| Антирадин, Ядер-Кола и аналоги | ↓ снижает | Применяется при использовании предмета; значение берётся из поля `radiationEffect` предмета |
| Радиоактивная еда / напитки | ↑ повышает | То же самое, значение положительное |
| Тimed-эффекты (зоны, урон) | ↑ повышает | Через существующую механику `activeTimedEffects` — пока вне скоупа |
| **Черта «Гуль»** | особая | Флаг-переопределение в агрегаторе модификаторов; точное поведение — открытый вопрос |
| **Черта «Дитя Атома»** | особая | Флаг-переопределение; точное поведение — открытый вопрос |

> Поле `radiationEffect` (целое, может быть отрицательным) должно быть добавлено в JSON-каталоги препаратов, еды и напитков (`chems.json`, `food.json`, `drinks.json`) для предметов, которые влияют на радиацию. Предметы без этого поля радиацию не меняют.

Радиация не может опуститься ниже 0 ни при ручном управлении, ни при автоматическом применении предметов.

### 4.3 Расчёт знаменателя ОЗ (`domain/characterCreation.js`)

Приложение не вводит «эффективный максимум» — знаменатель отображается как есть, даже если уходит в 0 или ниже. Решение о состоянии персонажа остаётся за столом.

```js
/**
 * Знаменатель в отображении Здоровья с учётом радиации.
 * Результат может быть ≤ 0 — приложение отображает его без ограничений.
 */
function getDisplayMaxHP(character) {
  const baseMax = getMaxHP(character); // существующая функция
  const radiation = character.radiation ?? 0;
  return baseMax - radiation;
}

/**
 * Применить лечение из предмета (еда / напитки / препараты).
 * currentHP не может подняться выше знаменателя,
 * но если уже выше — остаётся на месте (не срезается).
 */
function applyHealing(currentHP, healAmount, character) {
  const cap = getDisplayMaxHP(character);
  if (currentHP >= cap) return currentHP;          // выше потолка — не трогаем
  return Math.min(currentHP + healAmount, cap);    // лечим до потолка
}
```

> `HealthCounter` использует `getDisplayMaxHP` вместо `getMaxHP` для знаменателя.  
> Логика `applyHealing` применяется в обработчике использования лечащих предметов (Inventory / chems).

## 5. Компонент `EffectsPanel` — скетч интерфейса

```jsx
const EffectsPanel = ({ character }) => {
  const [isOpen, setIsOpen] = useState(false);
  const effects = useMemo(() => getAllActiveEffects(character), [character]);

  return (
    <View style={styles.effectsPanel}>
      {/* Заголовочная строка */}
      <TouchableOpacity style={styles.effectsHeader} onPress={() => setIsOpen(v => !v)}>
        <Text style={styles.effectsTitle}>{t('effects.sectionTitle')}</Text>
        <Ionicons
          name={isOpen ? 'remove-circle-outline' : 'add-circle-outline'}
          size={22}
          color={colors.gold}
        />
      </TouchableOpacity>

      {/* Содержимое спойлера */}
      {isOpen && (
        <View style={styles.effectsList}>
          {effects.length === 0 ? (
            <Text style={styles.effectsEmpty}>{t('effects.empty')}</Text>
          ) : (
            effects.map(effect => (
              <EffectRow key={effect.id} effect={effect} />
            ))
          )}
        </View>
      )}
    </View>
  );
};
```
