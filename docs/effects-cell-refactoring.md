# Рефакторинг ячейки «Эффекты»

**Статус:** Запланировано — не реализовано  
**Целевой экран:** WeaponsAndArmorScreen  

---

## 1. Текущее состояние

Ячейка «Эффекты» расположена в блоке «Основные характеристики» как одна из трёх ячеек во втором ряду сетки:

```
[ Инициатива ] [ Защита ] [ Рукопашный бонус ]
[ Эффекты    ] [ Сопр. яду ] [ Здоровье ]
```

- Рендерится через компонент `StatBox`
- Показывает только `activeTimedEffects` (временные эффекты с обратным отсчётом сцен)
- Отображает список меток `label + timeRemaining`
- Файл: `components/screens/WeaponsAndArmorScreen/WeaponsAndArmorScreen.js`, строки ~618–637

## 2. Целевое состояние

### 2.1 Расположение и размер

Ячейку «Эффекты» вынести из второго ряда сетки и разместить ниже блока «Основные характеристики» — отдельной строкой на всю ширину экрана, на одном уровне с другими полноширинными элементами.

```
[ Инициатива ] [ Защита ] [ Рукопашный бонус ]
[ Сопр. яду  ]              [ Здоровье        ]
─────────────────────────────────────────────
  Эффекты                                  [+]
─────────────────────────────────────────────
  (содержимое — видно при раскрытии)
─────────────────────────────────────────────
```

> Второй ряд сетки теперь содержит только «Сопр. яду» и «Здоровье» — без «Эффектов».

### 2.2 Поведение

| Свойство | Описание |
|---|---|
| **Ширина** | 100% контейнера (как у всех полноширинных блоков экрана) |
| **Высота** | Динамическая: подстраивается под количество строк с эффектами |
| **Заголовочная строка** | Слева — надпись «Эффекты», справа — иконка «+» |
| **Иконка «+»** | Toggle: открыть / закрыть содержимое спойлера |
| **Состояние по умолчанию** | Свёрнуто (collapsed) |
| **Анимация** | Плавное раскрытие (`LayoutAnimation` или `Animated`) — по возможности |

### 2.3 Структура заголовочной строки

```
┌────────────────────────────────────────┐
│  Эффекты                            +  │
└────────────────────────────────────────┘
```

- Левая часть: текст «Эффекты» (стиль `sectionTitle`)  
- Правая часть: TouchableOpacity с иконкой `Ionicons` — `add-circle-outline` (открыто) / `remove-circle-outline` (закрыто)  
- Иконка реагирует на нажатие в любой точке заголовочной строки (всю строку сделать нажимаемой)

### 2.4 Содержимое спойлера

Каждая строка — отдельный эффект:

```
  • [Иконка источника]  Название эффекта          (осталось: N сцен / постоянно)
```

Поддерживаемые источники эффектов (агрегируются в одном месте):

| Источник | Примеры |
|---|---|
| **Черты персонажа** | Радиационное исцеление, Иммунитет к яду |
| **Перки** | Бонусы атрибутов, боевые модификаторы |
| **Качества оружия** | Тихий, Точный, Бронебойный |
| **Эффекты оружия** | Bleeding, Burning, Knockdown |
| **Эффекты брони** | Stealth Field, Power Armor bonuses |
| **Моды оружия / брони** | Silencer, Night Vision |
| **Препараты / химикаты** | Stimpak, Med-X, Jet, Buffout |
| **Еда и напитки** | Nuka-Cola, Brahmin Steak |
| **Временные тimed-эффекты** | Любые с `timeRemaining > 0` |

Постоянные эффекты (от черт и перков) помечаются символом `∞` вместо таймера.

## 4. Компонент `EffectsPanel` — скетч интерфейса

```jsx
const EffectsPanel = ({ character }) => {
  const [isOpen, setIsOpen] = useState(false);
  const effects = useMemo(() => getAllActiveEffects(character), [character]);

  return (
    <View style={styles.effectsPanel}>
      {/* Заголовочная строка */}
      <TouchableOpacity style={styles.effectsHeader} onPress={() => setIsOpen(v => !v)}>
        <Text style={styles.effectsTitle}>{t('effects.sectionTitle')}</Text>
        <Ionicons
          name={isOpen ? 'remove-circle-outline' : 'add-circle-outline'}
          size={22}
          color={colors.gold}
        />
      </TouchableOpacity>

      {/* Содержимое спойлера */}
      {isOpen && (
        <View style={styles.effectsList}>
          {effects.length === 0 ? (
            <Text style={styles.effectsEmpty}>{t('effects.empty')}</Text>
          ) : (
            effects.map(effect => (
              <EffectRow key={effect.id} effect={effect} />
            ))
          )}
        </View>
      )}
    </View>
  );
};
```
