# Установка патча 544: окно локаций у игрока

Патч подготовлен от состояния **версии 543**. Файл установки:
`patchs/544-hub-location-display.patch`.

> Владелец: «По регламенту нельзя видеть, что внутри дочерней локации, пока в
> неё не войдёшь. Сейчас локации отображаются как сундуки, замки — как
> терминалы, вложенности нет: вижу сундук внутри запертой дочерней локации и
> могу открыть его, не заходя. Должно быть: вижу локацию, при входе — строчку
> про замок, после мини-игры взлома — сундук, открыв сундук — содержимое».

## Что меняется

| Файл | Что сделано |
| --- | --- |
| `server/locationNodeMarker.js`, `domain/locationNodeMarker.js` | маркер пространственного узла (`F2D20-LOC:`) в `lockLabel`: тип, рёбра графа, преграда и требование переживают старый сервер комнат; клиент восстанавливает потерянные `parentIds` по `childIds` |
| `domain/lootTrade.js` | `stampSessionNode` кладёт пространственную обёртку поверх маркера терминала/замка |
| `server/lootTradeSession.js` | нормализация разворачивает обёртку; запертый корень — граница видимости; `applyAtomicLootTake`/`applyAtomicTradeCommit` отклоняют прямой запрос за запертым/перекрытым родителем |
| `components/lootTrade/hackOutcome.js` | `kind=hub` приоритетнее пустого `childIds`: пустая/нераскрытая локация остаётся локацией |
| `components/lootTrade/PlayerLootTradeOverlay.js` | окно работает с восстановленным графом; иконка карты у локаций; замок не становится терминалом из-за `terminalStates`; локация/проверка не открываются как сундук; мета локации не «Пусто» |
| `src/room/roomProtocol.ts` | тип узла включает `hub`/`terminal`/`lock` и поля графа/преград |
| `__tests__/room/hub-location-display-544.test.js` | приёмка: маркер через старый WS, серверный запрет за родителем, цепочка локация → замок → сундук → содержимое |
| `docs/roadmap.md`, `docs/changelog.*.md`, `public/version.json`, `patchs/baseline.json` | версия/отсечка 544, тезис 34, «Осталось после патча 544» |

## Границы

- Закон снимка 529, адресный взлом 523, общая доска/журнал 535, gate-first 542
  и перекрытие проходов 543 сохранены.
- Старый сервер комнат получает только отображение/навигацию через маркер;
  серверная защита добычи/торговли за преградой работает на обновлённом
  сервере. Для полной защиты обновите и сервер комнат (`server/`).
- Отдельная семантика «контейнер внутри контейнера» не менялась.

## Установка через консоль

```bash
git fetch --no-tags origin arena/f90c80d8-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 544
```

## Проверки

- `npm run typecheck`: успешно.
- `npm test`: зелёные, кроме восьми заранее известных падений
  `__tests__/room/terminal-hacking-balance-496.test.js` — они падают теми же
  ошибками и на чистом дереве 543, патч 544 их не трогает.

## Откат

`git apply -R patchs/544-hub-location-display.patch` вернёт окно локаций,
маркер, серверную границу и версию к состоянию 543.
