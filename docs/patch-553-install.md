# Установка патча 553: пояснение шкалы дальности

Патч подготовлен от состояния **версии 552**. Файл установки:
`patchs/553-range-table-fix.patch`.

> **Вопрос владельца:** «В смысле короткая дистанция + мод на +1 дистанцию =
> дальняя???».

**Механика игры не менялась.** Патч 553 исправляет только описание дальности в
таблицах «было/стало» и добавляет проверку шага шкалы в приёмку 551.

## Что было не так в документах

В таблицах установок 551 и 552 у мода с `rangeModifier +1` («Длинный ствол»)
в колонке «было» стояла «Близкая». Получалось, будто один шаг перепрыгивает
категорию: «Близкая» + 1 = «Дальняя». Это неверно.

На самом деле шкала — **соседние категории**:

```
Близкая (C) → Средняя (M) → Дальняя (L) → Экстремальная (E)
```

Один шаг = одна соседняя категория: «Средняя» + 1 = «Дальняя», «Близкая» + 1 =
«Средняя». Через категорию дальность не прыгает.

## Как вёл себя старый дефект (проверено прогоном кода до 551)

| Оружие / мод | Старый код (до 551) | Сейчас (551 и далее) |
| --- | --- | --- |
| Охотничья винтовка без модов | «Средняя» (показывалась буква `M`) | «Средняя» |
| + «Короткий оптический» (без `rangeModifier`) | «Близкая» | «Средняя» |
| + «Длинный ствол» (`rangeModifier +1`) | «Средняя» — мод лишь возвращал базу, шага вверх не было | «Дальняя» |
| + прицел и длинный ствол вместе | «Средняя» | «Дальняя» |
| Меч + мод | придуманная дальность | пусто |

Причина: база считалась из **локализованной подписи** `rangeName` («Средняя»),
парсер её не узнавал и подставлял `0` — «Близкая». Поэтому мод +1 не поднимал
оружие до «Дальней», а только компенсировал дефект.
