## Новый список (что увидит игрок)

1. Игра в комнате с ведущим: лист уезжает ведущему, его решения приходят на лист
   и сохраняются.
2. Ведущий видит состояние героя: ОЗ, радиация, условия, ключевые показатели.
3. Локации с комнатами и переходами: здание, подвал, сундук — движение по местам.
4. Запертая дверь не пускает внутрь: сначала ключ или взлом.
5. Взлом замков: ячейки по восприятию и сложности, ограниченные попытки.
6. Взлом терминалов: четыре попытки, слова, скобки, доска по интеллекту, решение
   ведущего после провала.
7. Ключи и записки: найти, носить, оставить на складе, открыть дверь или сундук.
8. Ворота: взлом одного терминала открывает путь дальше.
9. Общий склад партии: положить и забрать может каждый, ведущий видит, что где.
10. Добыча и торговцы: выдача предметов, покупка и продажа по ценам торговца.

## Что осталось за списком (сознательно)

Лицензии и доступ к разделу Мастера, «канон хранилища», две панели склада,
экспорт/импорт JSON, карточки ключей в админке, дерево локаций у Мастера,
термины «команды Мастера» — это интерфейс и техника Мастера, игроку они ничего
не объясняют.

## Установка через консоль

```bash
git fetch --no-tags origin arena/a97ebb5a-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 554
```

После установки: `git add -A && git commit -m "Патч 554"`.
