## Согласованные рабочие допущения

- Все локации — `kind:'hub'`; чекбокс «Хаб» (`isCatalogHub`) включает режим
  папки. У папки нет родителя/выхода в форме (она сама родитель), остаются
  серверные комнаты; вложенность делается переносом стрелками.
- Дети узла в дереве — объединение без дублей: локации с
  `parentLocationId === node.id` (матрёшка) и не-локационные узлы из
  `node.links`. Игровой путь (`links`) не меняется — дерево только читает.
- Перенос локации в локацию ставит `parentLocationId` (как в 538); бросок на
  саму себя исключён, цикл матрёшки запрещён (`wouldCreateParentCycle`).
- И/ИЛИ сохранён из 538 и означает: войти в локацию можно, только пройдя обе
  преграды (И) или одну из них (ИЛИ). Ключ — отдельное поле, не в одной строке
  с замком/терминалом.
