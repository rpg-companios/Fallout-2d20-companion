## Форма ревизии (к согласованию; работы после этапа 1)

1. Каноничные id — человекочитаемые англ. слаги (comfort_grip,
   beta_wave_tuner...); mod_NNN исчезают.
2. Одна строка каталога на улучшение; оружие — applies_to_ids.
3. Колонки крафта (сложность/перк/редкость/материалы) — в рецептах по
   семействам оружия из таблиц книги (присланная таблица 2026-09-25 —
   источник).
4. Миграция сейвов: mod_NNN → канонический id на экземплярах (appliedMods,
   установленные моды, предметы); версия схемы не поднимается.
5. i18n ru/en под новые id; пересборка рецептов закрывает 53 «без рецепта».
