## 1.1. Редкость и ёмкость — разные вещи (слово владельца, 2026-09-23)

Два правила, чтобы никто (ни человек, ни код) не склеил колонки таблицы:

1. **Редкость мода ≠ материалоёмкость рецепта.** Колонка «Редкость» и
   колонка «Материалоёмкость» — независимые атрибуты; одно из другого не
   выводится. Пример из таблицы: Баллистическое Плетение — ёмкость 3,
   редкость Редкая; Экранированная Подкладка — ёмкость 6, редкость всего
   лишь Необычная. Материалы рецепта определяются ЁМКОСТЬЮ (кривая из
   CRAFTING-MAPPING.md), редкость на набор материалов не влияет.
2. **Редкость рецепта ≠ редкость создаваемого предмета.** Редкость в
   таблице — свойство РЕЦЕПТА (записи о крафте), а не предмета, который
   рецепт создаёт. Созданный мод несёт собственные атрибуты своей записи
   (data/equipment), редкость рецепта на него не переносится — ни в данных,
   ни в подписях окна крафта.

Следствие для окна крафта: если редкость рецепта показывается, то это
подпись самой строки рецепта, отдельная от ёмкости и не перекочёвывающая
в карточку созданного мода. Сегодня в приложении правила не нарушены:
редкость подписана только у материалов-ингредиентов (их собственное
свойство предмета из словаря материалов), у рецептов метки редкости нет.

Ультралёгкая — в таблице установки их нет; владельцу «пока непонятно, от

До ответа эти пять в окнах установки/крафта не появляются; крафт-рецепты
для них не пишутся.

## 2.5. Ответы владельца (2026-09-23, патч 332)

1. **Ёмкость ≠ сложность предмета.** Владелец: «ты сравниваешь данные
   таблицы крафта с параметрами предметов модов?» — да, это было неверное
   сравнение. Проверка по коду (332): `complexity` в данных модов брони
   сейчас НЕ используется приложением нигде (механики установки модов
   пока нет; сложность крафта берётся из рецептов). Данные модов НЕ
   трогаем; ёмкость крафта придёт из ЭТОЙ таблицы своим полем при патче
   крафта модов; собственный смысл `complexity` предмета (установка?)
   определим, когда дойдёт механика установки.
2. **15 недостающих модов — это моды ОДЕЖДЫ (костюмов).** Единственный
   мод, подходящий большинству костюмов, — подкладка из баллистического
   плетения. КОСТЮМЫ: Униформа Братства Стали, Повседневная одежда,
   Портупея, Военная форма, Дорожная кожа, Прочная одежда, Комбинезон
   Убежища (плетение + подкладки комбеза). Открыто: таблица эффектов
   (защита/цена/вес) — нужна для добавления.
3. **Ламинированная / Прорезиненная / Микроуглеродистая / Нановолоконная —
   уникальные моды брони синтов.** В общих модах их дубли
   (`mod_std_laminate`, `mod_std_rubberized`, `mod_std_microcarbon`) —
   лишние; судьба дублей — узкий вопрос (см. §3).
4. **Редкость — система «узнавания» рецептов** (слово владельца дословно
   по смыслу): обычные рецепты известны всем по умолчанию (не требуют
   перков и т.п.); необычные — получаются с определёнными перками
   (видны, но требуют перки); редкие — узнаются только от конкретного
   человека или найдя копию записанного рецепта, доступны по усмотрению
   ГМа, выдаются наградой или находятся запиской/голозаписью при
   зачистке мусора. Для редких — новая категория инвентаря «Рецепты»
   (названия предметов = названия рецептов); принцип как у драйвера
   МК II: применение предмета-рецепта снимает запрет; id предмета
   связан с id рецепта крафта (рецепты видны, требования видны, активны
   только после применения предмета-рецепта).
