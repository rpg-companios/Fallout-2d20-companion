## Ещё пара мелочей
- `emt` есть в приложении, но нет в PDF (заглушка, ХАР 1). Оставлен без изменений.
- Названия, где PDF содержит опечатку, написаны исправленно: «Охотник за бурей» (в PDF «Ухотник»), «Прицел с подсветкой» (в PDF «подстветкой»).
- «Мисс Удача»: в PDF стоит «Ранги: 1», но в тексте есть «ваш ранг» и шаг уровня 5, то есть рангов, скорее всего, больше. Я добавил 1 ранг, как в PDF.
- «Заряжай и стреляй»: ранг 3 в шапке, а описаны только 2.
- «Ломовые патроны» (`juryRiggedAmmo`) и остальные 8 id придуманы мной по английскому смыслу названия; переименуйте под ваши.
