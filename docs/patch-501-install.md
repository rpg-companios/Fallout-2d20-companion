# Установка патча 501: характеристики берутся из листа персонажа

> **Доска из трёх групп и новая логика подсказок — в `docs/patch-503-install.md`.**

> **Сейв из файла экспорта читается целиком в `docs/patch-502-install.md`.**

Патч подготовлен от состояния **версии 500** (коммит `98ab994`, ветка
`arena/054e6676-fallout-2d20-companion`). Он применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — тогда установщик подтянет
патчи 493–501 цепочкой.

## Вопрос и ответ

> «Почему при инт 10, я вижу 21 слово на терминале 5 сложности?
> Если 25-10 = 15????»

Формула из версии 500 верна: `N = max(4, 15 + 2·D − ИНТ)`, на сложности 5
это `25 − ИНТ`, то есть **15 слов при ИНТ 10** и 21 при ИНТ 4. Ошибка была
не в арифметике, а в том, откуда движок брал сам ИНТ.

Сетевой конверт публикации персонажа (`CHAR_PUBLISH`) устроен так:

```js
{
  characterId: 'char-1',
  name: 'Оператор',
  level: 7,
  data: {                          // <- сохранение персонажа из БД
    attributes: [                  // <- legacy-массив, а не словарь
      { name: 'INT', value: 10 },
      { name: 'LCK', value: 8 },
      …
    ],
    skills: [ { name: 'SCIENCE', value: 6 }, … ],
    selectedPerks: [ { perkId: 'hacker', index: 0 } ],
    equipment: { items: [ … ] }
  }
}
```

`server/roomRegistry.js` снимал обёртку `data` и отдавал в движок только её
содержимое. А `readAttribute()` в `server/terminalHacking.js` умел читать
лишь словарь `{ INT: { value: 10 } }` и массив записей с полями `id`/`key`.
У реального сохранения записи выглядят как `{ name, value }`, поэтому ИНТ и
УДЧ не находились вовсе и молча подменялись четвёркой:

```
clamp(readAttribute(snapshot, 'INT') || 4, 4, 10)  ->  4
passwordWordCount(5, 4) = 25 − 4 = 21 слово
```

Наука при этом искалась по полю `name`, поэтому **Наука 6 давала свои четыре
скобки и выглядела исправной** — именно поэтому несоответствие было таким
незаметным. Из‑за той же ошибки Удача всегда считалась равной 4 (шанс полного
возврата попыток 5 % вместо положенных 5–20 %), а «Хакер» не снижал
сложность в сетевой партии.

## Что исправлено

| Было (500) | Стало (501) |
|---|---|
| Сетевой лист: ИНТ 4, УДЧ 4, «Хакер» 0 | ИНТ 10, УДЧ 8, «Хакер» 1 |
| Доска на D5 при ИНТ 10: **21 слово** | **15 слов** |
| Шанс полного возврата при УДЧ 8: 5 % | 15 % |
| Имя оператора в сетевой партии терялось | Берётся из конверта |

Изменения только в чтении снапшота, баланс не тронут:

- `server/terminalHacking.js` — перед расчётом доски снапшот приводится к
  одному виду функцией `normalizeCharacterSnapshot()` (она экспортируется для
  тестов). Снимается обёртка `data`, в том числе строковый JSON; атрибуты и
  навыки одинаково читаются из живого стора (`{ INT: { base, total } }`), из
  legacy-сохранения (`[{ name, value }]`) и из прежних тестовых форм
  (`{ INT: { value } }`, `[{ id: 'science', rank: 6 }]`). Ключи сравниваются
  без регистра, поддерживаются `INTELLIGENCE`/`ИНТ`, `LUCK`/`УДЧ`,
  `SCIENCE`/`НАУКА`.
- Ранг «Хакера» теперь считается и для записей вида `[{ perkId, index }]`:
  если явного `rank` нет, ранг равен числу взятых копий перка.
- *Programmer’s Digest* ищется не только в `items`, но и в
  `equipment.items` / `inventory` — то есть в настоящем сохранении.
- `server/roomRegistry.js` передаёт движку весь опубликованный конверт, а не
  только `data`: имя оператора (`name`) больше не теряется, а обёртку снимает
  сам движок.
- Формула `25 − ИНТ`, 4 попытки, скобки по Науке, удача, словарь из
  12 308 слов, интерфейс без служебных строк, «О приложении» и все правила
  496–500 остаются без изменений.

## Регрессионная приёмка

Новый файл `__tests__/room/terminal-character-stats-501.test.js` (8 тестов)
проверяет весь путь «сохранение → публикация → реестр комнаты → доска»:

- `characterStats()` на реальном конверте: ИНТ 10, Наука 6, УДЧ 8;
- `createGame()` на D5: **15 слов**, 4 скобки, 15 % возврата, 4 попытки;
- контроль формулы: при ИНТ 4 по‑прежнему 21 слово;
- через `createRoomRegistry()`: доска из 15 слов, оператор «Оператор»;
- перк «Хакер» из `[{ perkId, index }]` снижает D5 → D4;
- *Programmer’s Digest* в `equipment.items`;
- строковый `data`, legacy-массив без обёртки, живой стор и старые формы;
- локальный резерв мини‑игры без сервера тоже даёт 15 слов.

## Через `apply-patch.sh` (основной способ)

```bash
./apply-patch.sh 501
```

Если вы всё ещё на `a62ec71` со старым установщиком
(`arena/c1c60b87-fallout-2d20-companion`), один раз переключите источник:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 501
```

`patchs/baseline.json` в ветке‑источнике равен `501`, поэтому при установке
точно до отсечки дерево приводится к коммиту патча целиком, а каталог
`patchs/` синхронизируется (файл `patchs/501-character-stats-snapshot.patch`
появится и локально). `./apply-patch.sh --status` до установки может написать
«Всё актуально» — ориентируйтесь на `public/version.json` и явно указывайте номер.

После установки: `public/version.json` → `501`, `patchs/baseline.json` → `501`;
закоммитьте изменения и **перезапустите сервис Node.js** (`server/` —
характеристики и доска считаются сервером). Веб‑сборку пересоберите.
Уже начатые партии нужно запустить заново (`Сброс` у Мастера), поскольку
доска 500 была сгенерирована с неверным ИНТ.

```bash
node -e "
const e = require('./server/terminalHacking.js');
const snap = { name: 'Оператор', data: {
  attributes: [{ name: 'INT', value: 10 }, { name: 'LCK', value: 8 }],
  skills: [{ name: 'SCIENCE', value: 6 }], selectedPerks: [] } };
const g = e.createGame({ config: { containerId: 't', name: 'T', difficulty: 5 },
  operatorClientId: 'p', operatorCharacterId: 'c', characterSnapshot: snap,
  now: 100, rng: () => 0.42 });
console.log('ИНТ', g.intelligence, '| слов', g.wordCount, '| скобок', g.bracketRanges.length);

```

### Прямой `git apply` без установщика

Патч‑файл не может содержать сам себя, поэтому при ручном наложении его нужно
скопировать в `patchs/` отдельно:

```bash
git apply patchs/501-character-stats-snapshot.patch
cp /path/to/501-character-stats-snapshot.patch patchs/
```
