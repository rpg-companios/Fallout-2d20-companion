# Установка патча 556: окно общего хранилища по образцу торговца

Патч подготовлен от состояния **версии 555**. Файл установки:
`patchs/556-storage-like-trader.patch`.

> **Слово владельца:** «Насчёт окна общего хранилища. Оно должно было выглядеть
> и работать по аналогии с экраном торговца. Только без функций отслеживания
> цен и крышек. Т.е обмен без денег».

## Как это выглядит и работает

1. Игрок открывает «Общее хранилище» из инвентаря. Окно — как у торговца:
   шапка с иконкой, две панели, внизу полоса с «Очистить» и «Перенести».
2. Слева «Предметы персонажа»: строку можно отправить на склад кнопкой
   «Положить» или «Положить всё». Справа «Общее хранилище»: «Забрать» или
   «Забрать всё».
3. Выбранное сначала лежит в сером буфере внутри панели. Клик по строке буфера
   снимает одну вещь, крестик убирает строку целиком; «Очистить» сбрасывает
   весь буфер.
4. Ничего не переносится, пока не нажата «Перенести»; после нажатия уходит одна
   атомарная операция, и только по ответу сервера меняется инвентарь.
5. На телефоне панели переключаются вкладками, как в окне торговца.
6. У Мастера — просмотр состава склада и трансляция ключей; кнопок переноса у
   него нет.

## Установка через консоль

```bash
git fetch --no-tags origin arena/a97ebb5a-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 556
```

После установки: `git add -A && git commit -m "Патч 556"`.
