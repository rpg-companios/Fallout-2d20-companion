# Установка патча 525: входная модалка точки и светлый замок

Патч подготовлен от состояния **версии 524** (коммит `91d0000`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–525
цепочкой. Файл установки: `patchs/525-lock-entry-light.patch`.

> Владелец: «Мини-игра на взлом не должна сразу показываться. А то сейчас
> интерфейс как-бы игры запустился, а потом надо в нём нажать "взломать" и
> уже загружается игра. Плюс гамму интерфейса взлома замка надо изменить на
> светлую, не под терминал. Можно за основу взять гамму модалок. Для взлома
> игры пусть сначала будет модалка, как для локации и кнопками "взломать",
> только без "покинуть локацию" кнопки».

## Что изменено

### 1. Сначала — окно точки, потом доска

`components/lootTrade/StandaloneCheckModal.js` (новый файл): по структуре
повторяет окно локации — карточка точки со сложностью, кнопки «Смотреть» и
«Взломать» в футере. Кнопок «Покинуть локацию» и «Свернуть» нет: отдельно
выданная точка проверки не является локацией.

`PlayerLootTradeOverlay.js`:

- для отдельно выданной проверки через `terminal.issue` (`directTerminalContext`)
  и для резервной выдачи как одиночной сессии-локации (`standaloneCheckSession`)
  мини-игра больше не монтируется сразу;
- «Взломать» ставит `terminalSelection` с `autoStart: true` — окно доски
  появляется уже с собранными ячейками, отмычками и стрелками;
- «Смотреть» открывает доску без автозапуска (наблюдение за чужой партией);
- «Взломать» сразу отмечает одноразовый доступ на трансляцию (патч 506),
  «Смотреть» его не расходует; после закрытия доски входная модалка показывает
  «ДОСТУП ИСПОЛЬЗОВАН». Сессия Мастера остаётся активной.
- Выбор точки привязан к `accessKey`: новая выдача Мастера с новым `accessId`
  снова начинается с входной модалки, а не с «залипшей» старой доски.

`LockPickingModal.js`: убрана внутренняя кнопка «Взломать» и пустая
«как бы запущенная» раскладка. Пока доски нет, окно показывает подсказку
`player.checkWaitingBoard` / `player.checkEntryHint`, а не пустые ячейки и
неактивные стрелки.

### 2. Светлая гамма

`components/lootTrade/lockPickingStyles.js` (новый файл) — общий каркас для
входной модалки и окна доски. Импортирует `lootTradeFormStyles` из
`ContainerFormModal.js` и `ADMIN_MODAL_PALETTE` из `adminModalTheme.js`
(правило `docs/ui-modals-rules.md`): базовые `overlay/card/title/label/footer/
btn/saveBtn/cancelBtn` не дублируются, в новом модуле только ячейки, стрелки,
строка статуса и карточка точки. Цвета светлые (`#f4f4f4`, `#ffffff`, тёмный
текст), состояния ячеек — светло-зелёный / светло-красный / серый.

`terminalHackingStyles.js` и `TerminalHackingModal.js` не тронуты: зелёная
гамма осталась у терминала.

### 3. Что сохранено

- Мини-игра 520: `N = 12 − PER + 2·D`, отмычки, позиционные ячейки, четыре
  стрелки, спас-бросок Удачи, «Да/Нет» Мастера, один взлом на `accessId`.
- Исправления 524: один `start` на открытие, поиск отмычек во всех формах
  инвентаря, автоматический локальный резерв для старого сервера, адресные
  отказы вместо «Действие не выполнено», скрытое окно локации под мини-игрой.
- «Покинуть локацию» в **настоящей** локации на месте, закрывает окно с
  первого нажатия и не гасит сессию Мастера.
- Законы 522 (единый предмет, без игровых лимитов) и 523 (граф, граница
  видимости, адресный взлом, общие ресурсы) не изменились; защита сервера,
  проверки ролей и валидация сообщений не ослаблены.
- Парные RU/EN строки: добавлены `player.checkEntryHint` и
  `player.checkWaitingBoard`.

## Проверки

- `npm run typecheck`, `npm run build`, `npm test` (полный набор).
- `git apply --check patchs/525-lock-entry-light.patch` от дерева 524.
- `./apply-patch.sh 525` от версии 524 и полная цепочка 493–525 от чистого
  `main` `a62ec71`; побайтовое сравнение установленных деревьев.
- Рендер-тесты: входная модалка без «Покинуть локацию», доска не монтируется
  до «Взломать», по `autoStart` сразу есть ячейки и активные стрелки, внутри
  окна доски нет второй кнопки «Взломать».
- Живой сервер комнат: `/version.json` = 525/4/95+95 и WS-проба взлома.
- После установки на боевой площадке перезапустить процесс сервера комнат,
  чтобы подхватить обновлённую статику и файлы `server/`.
