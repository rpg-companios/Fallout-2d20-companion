## Согласованные рабочие допущения

- Выражение — массив токенов: операнд `{type:'check', id}` и оператор
  `{type:'op', op}`; `+` = И, `/` = ИЛИ. Полное выражение нечётной длины,
  строгое чередование, начинается и заканчивается операндом.
- `+` связывает сильнее `/`, скобок нет: `A + B / C` = `(A И B) ИЛИ C`.
- «Хаб» — булев флаг `isCatalogHub` на локации (`kind:'hub'`); поля
  `parentLocationId`/`exitLocationId` хранятся только у локаций.
- Лимит «две проверки» снят для выражения; legacy-поле `linkedCheckIds` в
  сессионных нормализаторах по-прежнему ограничено двумя для старых читателей.
