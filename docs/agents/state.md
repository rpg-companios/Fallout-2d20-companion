  коммитной версией, не править на глаз.
- Установщик файлы не теряет (починен возврат «остатков отката»), но
  крепить результат установки коммитом — обязанность владельца; установщик
  теперь сам печатает команду.
- Связи «робо → людское» держать только в данных: зашитая карта жила в коде
  и указывала на несуществующие id (мёртвый груз, 311–312).
- Патч, трогающий бинарные файлы (иконки и пр.), собирать только
  `git diff --binary` — обычный diff молча выбрасывает бинарь, установщик
  падает с «cannot apply binary patch» (320).
- Проводка «кнопка → окно» проверяется приёмочным тестом (урок 319: модалка
  жила в коде, но кнопка годами звала заглушку).
