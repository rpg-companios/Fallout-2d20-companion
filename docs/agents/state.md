## Состав приложения (игровыми терминами)

- **Герои.** Менеджер: создание/загрузка, папки, дубликаты, аватары, перенос
  файлом, облачная синхронизация (Google Drive). Автосохранение меняется
  через полсекунды после последнего действия.
- **Экраны.** Персонаж (SPECIAL в каноне Сила-Восприятие-Выносливость-
  Харизма-Интеллект-Ловкость-Удача, навыки, ОЗ, удача-очки), Снаряжение
  (оружие/броня, окна улучшения, силовая броня), Перки и черты, Инвентарь
  (сумка, вес, расходники), «Игровой сеттинг» (пока заглушка).
- **Роботы.** Анатомия — из данных: конечность-оружие / конечность со
  встроенным оружием / рука для ношения (может или нет); планы тела
  (не только гуманоиды); защита слоями (обшивка/броня/рама). Оружие живёт
  в ладони, вмонтированное в конечность и собственная атака конечности —
  на всех трёх местах моды ставятся и переживают сохранение.
- **Оружие.** Каталог — JSON сеттинга. Вариант (`trueItemId`) = «это то же
  оружие, только с другим именем» («Опасная бритва»; робо-версии 314:
  Огнемёт Мистера Помощника = Огнемёт и т.д.). Моды: единая правда — список
  id на экземпляре (311); заводские моды записи (`modIds`, 312 — Авто-10мм
  с авто-ресивером); списание зарядов за выстрел (296/298).
- **Прочее.** Крафт: из инвентаря — окно с квадратами категорий (еда,
  напитки, препараты, взрывчатка, оружие, броня, силовая броня, патроны;
  пустые данными видны), рецепты-спойлеры (доступные белые, недоступные
  серые; внутри — материалы по редкости обычные/необычные/редкие и кнопка
  «Создать»; если можно больше одной — окно «сколько штук», по умолчанию 1),
  крафт с проверкой навыка и отчётом; «Назад» — к квадратам, «Закрыть» —
  в инвентарь. Разбор хлама, выживание (голод/жажда/сон через расширение
  состояния), локали ru/en, PWA (обновление по кнопке), премиум-статус.

## Уроки (не повторять)

- ПРОТОКОЛ ВОПРОСОВ (331, слово владельца после 329→330): любое
  недопонимание или разночтение — СПРАШИВАТЬ владельца и «спихивать» на
  него описание деталей, даже если ответ кажется очевидным. Два патча на
  правку недопонимания хуже одного вопроса до работы. Вопросы в отчёте
  выделять ЯВНО: заголовок «ВОПРОСЫ — жду ответа по номерам», не абзацем.

- Песочница агента периодически теряет историю коммитов (`.git` откатывается,
  дерево живёт) — коммит и пуш после КАЖДОГО шага.
- Повреждение байта в файлах патчей после сбоя песочницы — сверять с
  коммитной версией, не править на глаз.
- Установщик файлы не теряет (починен возврат «остатков отката»), но
  крепить результат установки коммитом — обязанность владельца; установщик
  теперь сам печатает команду.
- Связи «робо → людское» держать только в данных: зашитая карта жила в коде
  и указывала на несуществующие id (мёртвый груз, 311–312).
- Патч, трогающий бинарные файлы (иконки и пр.), собирать только
  `git diff --binary` — обычный diff молча выбрасывает бинарь, установщик
  падает с «cannot apply binary patch» (320).
- Проводка «кнопка → окно» проверяется приёмочным тестом (урок 319: модалка
  жила в коде, но кнопка годами звала заглушку).
