# Установка патча 497: канонические 4 попытки и доска «последовательности»

Патч подготовлен от состояния **версии 496** (коммит `f0769a4`, ветка
`arena/054e6676-fallout-2d20-companion`). Он применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — тогда установщик подтянет
патчи 493, 494, 495, 496 и 497 цепочкой.

## Принятые правила владельца

1. **4 попытки на всех сложностях**, потолок 4. Скобки возвращают попытки,
   но выше 4 не поднимают. Полный сброс возвращает **к 4**, а не добавляет
   ещё один комплект (это было расхождением с каноном в 496).
2. **Число слов** `N = max(4, 20 + 2·D − ИНТ)`.
   При ИНТ 10: `10, 12, 14, 16, 18, 20`; при ИНТ 4: `16, 18, 20, 22, 24, 26`.
   На сложности 5 это **26 / 20 слов** — доска выросла, чтобы скобки её не съедали.
3. **Длина** `L = 4 + D` (без изменений), словарь — те же 12 308 реальных слов.
4. **«Последовательность вместо количества букв»**: на D≥1 доска собирается
   из реальных слов, близких по набору букв (не менее `L−3` общих) и различающихся
   **порядком** (не более 2 совпавших позиций). Подсказка по-прежнему показывает
   только число совпавших позиций. На D0 — анаграммные семьи (`POST/SPOT/POTS`)
   и пароль-выброс: нужно найти самое непохожее слово.
5. **Пароль выбирается внутри собранного набора**, из середины распределения
   «похожести на остальных». Иначе он угадывается эвристикой «самое
   центральное слово», либо её зеркалкой «самое непохожее». Обе проверены:
   после правки дают 0 % на досках без бонусов.
6. **Скобки**: Наука 0 — скобок нет; иначе число пар по сложности
   `{0:4, 1:4, 2:3, 3:3, 4:2, 5:2}`. Эффект детерминирован Наукой
   (слов убрать / попыток вернуть):

   | Наука | Эффект |
   |---|---|
   | 1 | 50 % убрать 1 слово, 50 % +1 попытка |
   | 2 | 1 слово |
   | 3 | 1 слово + 1 попытка |
   | 4 | 2 слова + 1 попытка |
   | 5 | 1 слово + 2 попытки (`SCI5_MONO` меняет на 2+2) |
   | 6 | 2 слова + 2 попытки |

7. **Удача 4–10** даёт `p = 0.05 + 0.025·(УДЧ−4)` = 5…20 % на **полное
   восстановление** при каждом использовании скобки. На Науке ≥2 «словесная»
   часть пакета остаётся; на Науке 1 удача заменяет весь эффект.
   Ограничения «раз за терминал» больше нет, но попытки всё равно ≤ 4.
8. **Пол неоднозначности поднят на D4–D5**: после любого первого неверного
   хода остаётся ≥4 кандидата (цель ремонта — 8). Это возвращает напряжение:
   думающий игрок без бонусов выигрывает ~82–88 %, а не 95–100 %.

## Замеры на реальном движке (30 досок × 6 прогонов, ИНТ 10, УДЧ 4)

| Стратегия | D0 | D1 | D2 | D3 | D4 | D5 |
|---|---|---|---|---|---|---|
| Слепой перебор, Наука 0 | 42 % | 32 % | 27 % | 27 % | 28 % | **17 %** |
| Слепой перебор, Наука 6 | 100 % | 100 % | 100 % | 100 % | 59 % | **47 %** |
| Думающий, Наука 0 | 98 % | 94 % | 94 % | 96 % | **82 %** | **88 %** |
| Думающий, Наука 3 / 6 | 100 % | 100 % | 100 % | 100 % | 100 % | **100 %** |
| «Самое центральное слово» | 7 % | 17 % | 13 % | 10 % | 0 % | 13 % |

Низкие сложности остаются лёгкими по замыслу: «на 1-й сложности пара попыток
и подсказка — всё решил». На D5 слепой перебор 17–47 % (47 % устраивает
владельца), думающий 88 % без бонусов и 100 % при удачных скобках.

## Через `apply-patch.sh` (основной способ)

```bash
./apply-patch.sh 497
```

Если вы всё ещё на `a62ec71` со старым установщиком
(`arena/c1c60b87-fallout-2d20-companion`), один раз переключите источник:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 497
```

`./apply-patch.sh --status` до установки может написать «Всё актуально»:
ориентируйтесь на `public/version.json` и явно указывайте номер патча.
`patchs/baseline.json` в ветке-источнике равен `497`, поэтому при установке
точно до отсечки дерево приводится к коммиту патча целиком, а каталог
`patchs/` синхронизируется (файл `patchs/497-sequence-board-canon-attempts.patch`
появится и локально).

После установки:

- `public/version.json` → `497`, `patchs/baseline.json` → `497`;
- закоммитьте изменения (`git add -A && git commit -m "Патч 497"`);
- **перезапустите сервис Node.js** (`server/`): общие доски комнат создаются
  сервером, локальный резерв на клиенте работает сразу.

### Прямой `git apply` без установщика

Патч-файл не может содержать сам себя, поэтому при ручном наложении его нужно
скопировать в `patchs/` отдельно:

```bash
git apply patchs/497-sequence-board-canon-attempts.patch
cp /path/to/497-sequence-board-canon-attempts.patch patchs/
```
