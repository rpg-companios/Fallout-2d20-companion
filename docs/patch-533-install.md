# Установка патча 533: откат избыточных правок 531/532

Патч подготовлен от состояния **версии 532** (коммит `c0a9513`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–533
цепочкой. Файл установки: `patchs/533-rollback-ui.patch`.

> Владелец: «есть ощущение, что ты стал делать избыточные правки. Ты удалил
> только те стили, что я сказал? Или больше? Я просил счётчик?» и затем
> «вот это откатить» с точным перечнем лишних правок.

## Что откатывается

### 1. Лишние style-правки патча 531

Восстановлено (кроме четырёх правил, которые владелец называл сам):

| Файл | Возвращено |
| --- | --- |
| `components/lootTrade/lockPickingStyles.js` | `arrowButton`: `borderRadius: 6`, `borderWidth: 1.5`, `borderColor: '#9a9a9a'`, `paddingVertical/paddingHorizontal: 0`; `arrowPad`: `borderWidth: 1` + `borderColor`; `arrowSpacer: 58×50`; удалены `statusLeft` и `flexShrink/maxWidth` у `arrowsHint` |
| `components/lootTrade/LockPickingModal.js` | `modalStyles.btn` и `modalStyles.saveBtn` снова в массиве стилей кнопки стрелки; иконка снова `size={30}`; строка статуса снова `<View>` без `statusLeft` |

**Оставлены ровно четыре удаления по слову владельца:** `flex: 0`,
`backgroundColor: '#dadada'`, `width: 58`, `height: 50` в `arrowButton`.
Центрирование `alignItems/justifyContent: 'center'` сохранено (это было
отдельное требование 531). Светлая палитра, заливка области, шаг 16 и
`ScrollView` не тронуты.

### 2. Лишние интерфейсные правки патча 532

- Счётчик `«Отгадано N из M»` снова считает только зелёные ячейки.
- Удалена строка `«Угаданные позиции (X из Y) сохранены»` из панели
  «Подход завершён» и ключ `progressSaved` из RU/EN.
- `arrowsHint`, `greyHint`, `newAttemptHint` возвращены к формулировкам
  527/531 (байтово равны блоку `lock` версии 531).

## Что НЕ откатывается

Вся механика патча 532: `resumeLockGame()`, `knownPositions`, курсор на первой
неотгаданной ячейке при поломке, продолжение тем же секретом после «Ещё
подход» / «кончились заколки» / смены оператора, общая доска для привязанных
комнат, `adoptSharedLockGame()`, локальная память доски, сброс победой или
повторной выдачей Мастера. Также сохранены законы 524–531 и **закон снимка
529** (сервер не правит `room.lastSnapshots`).

## Известные следствия отката (приняты владельцем)

- Удалены `statusLeft` и `flexShrink/maxWidth`, поэтому длинная подсказка
  правил снова может выходить за границы модалки одной строкой — требование
  переноса из 531 откачено по прямому указанию.
- Подсказки снова говорят «взлом необходимо начать сначала» и «серые стрелки
  нужно повторить», хотя движок прогресс сохраняет. Это текстовое
  несоответствие оставлено как часть отката.
