# Установка патча 537: многоуровневые локации и переходы — проект

Патч подготовлен от состояния **версии 536** (коммит `189e227`, ветка
`arena/0fa5e3ce-fallout-2d20-companion`). Файл установки:
`patchs/537-location-level-design.patch`.

> Владелец: «Насчёт связывания и блокировки. Это не то чтобы прям
> актуальненько… Мы обсуждали создание многоуровневой локации… некий аналог
> левел-дизайна… чтобы мастер мог создать что-то типа „Города" или „Мира"…
> Поэтому к блокировке локаций, вложенности элементов хочу подойти
> основательно». Уточнения: переходы между локациями, Мастер сам решает, что
> запереть руками; блокировка универсальная (обвал, ловушка, сигнализация —
> любой нарратив), игромеханически прохода нет; карту пока не трогаем (видение —
> компаньон + Owlbear из админских данных); объём — только проект.

менялись. Меняются только документы и версионная обвязка:

## Согласованные решения

- Переходы между локациями; Мастер перекрывает/открывает вручную, причина —
  свободный текст. Игромеханически прохода нет, нарратив любой.
- Взламываемый замок (существующая мини-игра) vs глухая преграда (снимает только
  Мастер). Направленность `A→B` / `B→A` независима.
- Без новых сущностей: узлы `hub/terminal/lock/loot/merchant` + рёбра графа 523.
- Карта и автоправила — задел на будущее, не реализуются.
- Инварианты 523/529/530/535 сохраняются.
