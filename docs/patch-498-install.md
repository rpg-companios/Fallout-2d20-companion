## Что изменилось ровно по просьбе владельца

| Было | Стало |
|---|---|
| «Сложность 3 · пароль 7 букв» в карточке, окне взлома и списке вложений | «Сложность 3» |
| Чипы формы `0 · 4`, `1 · 5`, … `5 · 9` и подпись «Сложность · длина пароля» | Чипы `1`, `2`, `3`, `4`, `5`, подпись «Сложность» |
| «Сервер комнат не поддерживает общий взлом — партия идёт локально на этом устройстве» | Строки нет; локальный резерв работает молча |
| Длинная подсказка про Хакера, 4 попытки, `N = 20 + 2·D − ИНТ`, Науку и Удачу в форме и админ-панели | Подсказки нет |
| Сложность `0` можно было выбрать в форме | В форме только `1–5`; `0` остаётся **эффективной** сложностью у игрока с «Хакером», когда он снижает `1` |
| Фраза «Заблокировать терминал после провала всех попыток» кремово-жёлтая (`#e6e0c6`) на светло-серой форме | Тёмно-серая (`#222222`); галочка чекбокса тоже тёмно-серая |

Механика взлома **не менялась**: 4 попытки, `N = max(4, 20 + 2·D − ИНТ)`,
пакеты Науки, удача 5–20 %, доска «последовательности», словарь
12 308 слов, экран «О приложении» и все проверки 497 на месте.
Изменены только строки, условия выбора сложности в UI и цвет подписи.

## Через `apply-patch.sh` (основной способ)

```bash
./apply-patch.sh 498
```

Если вы всё ещё на `a62ec71` со старым установщиком
(`arena/c1c60b87-fallout-2d20-companion`), один раз переключите источник:

```bash
git fetch origin arena/054e6676-fallout-2d20-companion
sed -i 's|arena/c1c60b87-fallout-2d20-companion|arena/054e6676-fallout-2d20-companion|' apply-patch.sh
./apply-patch.sh 498
```

`patchs/baseline.json` в ветке-источнике равен `498`, поэтому при установке
точно до отсечки дерево приводится к коммиту патча целиком, а каталог
`patchs/` синхронизируется (файл `patchs/498-terminal-ui-cleanup.patch`
появится и локально). `./apply-patch.sh --status` до установки может написать
«Всё актуально» — ориентируйтесь на `public/version.json` и явно указывайте номер.

После установки: `public/version.json` → `498`, `patchs/baseline.json` → `498`;
закоммитьте изменения. Перезапуск сервиса Node.js для этого патча **не нужен**
(серверные правила не менялись), но обновлённую веб-сборку следует пересобрать.

### Прямой `git apply` без установщика

Патч-файл не может содержать сам себя, поэтому при ручном наложении его нужно
скопировать в `patchs/` отдельно:

```bash
git apply patchs/498-terminal-ui-cleanup.patch
cp /path/to/498-terminal-ui-cleanup.patch patchs/
```
