# Установка патча 535: «Мастер решает» + общая доска привязанных комнат

Патч подготовлен от состояния **версии 534** (коммит `a216291`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–535
цепочкой. Файл установки: `patchs/535-gm-decision.patch`.

> Владелец: «Это подходит: пригодится единый штатный выход „Мастер решает" —
> тот же паттерн „Да/Нет", что уже есть у терминала, но доступный для любой
> спорной ситуации… Чтобы админ мог блокировать/открывать замки по своему
> усмотрению. И давай дальше по списку делать». Уточнения: одним патчем с
> пунктом 1 плана; оба пути (запрос игрока и ручной переключатель);
> «открыть» = сразу ACCESS GRANTED; «сейчас замки, но оставить место для
> манёвра».

## 1. «Мастер решает»

| Слой | Что добавлено |
| --- | --- |
| `server/protocol.js`, `src/room/roomProtocol.ts` | `gm.decisionRequest`, `gm.decisionState`, `gm.decisionResolve` + 4 кода отказов |
| `server/roomRegistry.js` | `room.gmDecisions`, `requestGmDecision()`, `resolveGmDecision()`, `getGmDecisions()`, `GM_DECISION_KINDS = ['lock.open']`, `grantGmAccess()`, `gmWonGame()` |
| `server/lockPicking.js` | `shouldBlockLock({ gmBlocked })`, `gmWonLockGame()`; `LOCK_BLOCK_POLICY.enabled` оставлен `false` |
| `server/roomServer.js` | три новых кадра, `broadcastGmDecisions()`, рассылка общего контура для сессий |
| `src/room/roomStore.ts` | `gmDecisions` в состоянии комнаты, обработчик кадра, `requestGmDecision` / `resolveGmDecision` / `setGmLockState` |
| `components/lootTrade/GmDecisionPromptHost.js`, `gmDecisionPrompt.js`, `App.js` | глобальный вопрос «Да/Нет» поверх любого экрана, чистый отбор нерешённых запросов |
| `components/lootTrade/LockPickingModal.js` | панель заблокированной точки, «Попросить Мастера», ожидание/отказ |
| `components/screens/LootTradeScreen/LootTradeScreen.js` | кнопки «Заблокировать» / «Открыть» в карточке точки |
| RU/EN словари | раздел `gmDecision`, строки `lock.gmBlocked*`, `lock.askGm`, `livePanel.gmBlock/gmOpen` |

Правила: решает только владелец комнаты; повторный запрос по той же точке не
создаёт второй диалог; «Да»/«Открыть» выдают выигранную доску с
`hackedByGm`, снимают блокировку и пишут общее событие `hacked`; «Нет»
оставляет точку закрытой. Неизвестный вид решения сервер отвергает
`GM_DECISION_KIND`, клиент берёт общую пару строк. Новых видов ситуаций не
придумано — только место для них.

## 2. Пункт 1 плана: общий контур

`boundScopeRooms()` обходит `roomCodes` до неподвижной точки;
`syncSharedTerminalScope()` объединяет **все** `terminalStates` и
`accessEvents` комнат контура. Точка, выданная в одной комнате, появляется во
всех; доска терминала и журнал доступа расходятся вместе с замком; комната,
подключившаяся позже, перенимает идущий взлом; `reissue` по-прежнему сбрасывает
доску. Автоблокировка 526 не возвращалась. Защита сервера (роль, членство,
лимит кадра, валидация JSON, закон снимка 529) не ослаблена.
