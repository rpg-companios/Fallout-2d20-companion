# Установка патча 551: «Тренированный» и дальность оружия

Патч подготовлен от состояния **версии 550**. Файл установки:
`patchs/551-educated-and-range.patch`.

> **Слова владельца:** «не работает перк тренированный, он должен давать очки
> навыков. И короткий оптический прицел на охотничьей винтовке снижал дистанцию».

Две независимые ошибки листа персонажа. Обе — не в данных, а в конвейере:
механика читала поле, предназначенное для отображения, либо не читала бонус вовсе.

## Что было не так

### 1. «Тренированный» не давал очков навыков

Каркас перка (`domain/perks/educated.js`) возвращал `{ skillPoints: 2 }` и
**не смотрел на ранг**, а ранг в контексте эффекта лежит в `ctx.state.rank`
(`createPerkEffectContext` не разворачивает state — так же его читают
`lifeGiver`, `strongBack`, `toughness`). Но главное: экран персонажа вообще не
читал `perkBonuses.skillPoints` — пул навыков считался только как
`INT + 9 + (level-1)`. В итоге перк был «мёртвым» при любом ранге.

### 2. «Короткий оптический» понижал дальность

В i18n-каталоге оружия поле `rangeName` — **локализованный текст** («Средняя»,
«Близкая»), а механика дальности хранится буквой `range`: `C` / `M` / `L` / `E`.
Конвейер модов (`applyWeaponMods`) читал `range_name`/`rangeName` **раньше**
буквы `range`, не распознавал локализованную строку и подставлял `?? 0` —
«Близкая». Поэтому **любой** установленный мод, даже без `rangeModifier`
(«Короткий оптический» его не имеет), понижал дальность: у охотничьей винтовки
«Средняя» превращалась в «Близкую».

## Что меняется

| Файл | Что сделано |
| --- | --- |
| `domain/range.js` | новый `baseRangeIndex`: механика читает только машинные источники — буква `range` → каноническое имя → индекс; локализованный текст (`rangeName`) не парсится. `resolveWeaponRangeFields` использует тот же порядок (буква важнее `rangeName`) |
| `domain/enrichItem.js` | `applyWeaponMods` берёт базу через `baseRangeIndex`; мод без `rangeModifier` дальность не меняет, мод с `rangeModifier` сдвигает на шаги; у ближнего боя дальность не выдумывается (`undefined` вместо Close) |
| `modules/fallout/screens/WeaponsAndArmorScreen/modal/WeaponModificationModal.js` | превью модификации считает дальность тем же `baseRangeIndex`, в модель пишет канонические `range_index`/`range_name`, локализацию делает UI (`rangeDisplayLabel`) |
| `domain/perks/educated.js` | бонус = 2 очка × действующий ранг (`ctx.state.rank`) |
| `domain/characterCreation.js` | новый `getSkillPointsAvailable` = `getSkillPoints` + `perkBonuses.skillPoints` |
| `modules/fallout/screens/CharacterScreen/CharacterScreen.js` | пул навыков считается через `getSkillPointsAvailable` с бонусами перков |
| `__tests__/perks/educated-skill-points-551.test.js` | приёмка перка (7) |
| `__tests__/equipment/weapon-range-mod-steps-551.test.js` | приёмка дальности (8) |
| `docs/schema/08-perks-influence.md`, `docs/schema/03-attributes-skills.md` | «Тренированный» переведён из «каркасно» в «реализован»; формула пула навыков дополнена перк-бонусом |
| `docs/agents/state.md`, `docs/roadmap.md`, `docs/changelog.*.md`, `public/version.json`, `patchs/baseline.json` | запись 551, тезис 41, версия/отсечка 551 |

## Поведение после патча

| Ситуация | Было | Стало |
| --- | --- | --- |
| «Тренированный», 1 ранг | 2 очка «в никуда» | +2 к пулу навыков |
| «Тренированный», 3 ранга | 2 очка «в никуда» | +6 к пулу навыков |
| «Тренированный» погас по книге (уровень) | 2 очка «в никуда» | 0 очков |
| Перк снят | — | пул возвращается к базе |
| Охотничья винтовка + «Короткий оптический» | «Средняя» → «Близкая» | «Средняя» (без изменений) |
| Охотничья винтовка + мод с `rangeModifier +1` («Длинный ствол») | «Средняя»: мод лишь возвращал базу после дефекта, шага вверх не было | «Дальняя» (Средняя + 1 шаг) |
| Оружие ближнего боя + мод | дальность «Close» у меча | дальность пустая (не выдумывается) |
| Установка мода без `rangeModifier` | дальность могла «упасть» | дальность не меняется |

## Границы

- Потолок навыка не менялся: `canChangeSkillValue` / `validateSkills` попрежнему
  ограничивают ранг 6-м (на 1-м уровне — 3-м). Очки перка лишь увеличивают пул.
- Действуют только активные ранги (закон 412): погасший перк очков не даёт.
- Данные каталога не правились: `rangeName` остаётся подписью для отображения,
  `range` — единственный механический код дальности.
- Бонус «Тренированного» начисляется в пул распределения навыков (экран
  персонажа в режиме распределения после повышения уровня). Отдельного «личного
  счётчика очков перка» нет — это и есть существовавшая механика пула.

персонажа и модалка модификаций.
