# Установка патча 524: взлом замка и окно локации

Патч подготовлен от состояния **версии 523** (коммит `601e658`, ветка
`arena/054e6676-fallout-2d20-companion`). Применим и к чистому `main`
`a62ec7109b50ad720641a4fdeb48f1de865d8742` — установщик подтянет 493–524
цепочкой. Файл установки: `patchs/524-lock-picking-fix.patch`.

> Владелец: «Я попробовал взломать замок. Открыл замок (нажал взлом), сходу
> надпись "действие не выполнено", Отмычки не находит, ячеек нет, стрелки не
> нажимаются. В модалке "покинуть локацию" зачем-то показано и при этом не
> работает».

## Что исправлено

### 1. Одна доска на одно нажатие «Взломать»

`components/lootTrade/lockAutoStart.js` — чистые правила автозапуска. Ключ
дедупликации больше не содержит `terminalState.accessId`: состояние комнаты,
пришедшее после первого рендера, не отправляет второй `start`. Финальные
статусы (`won`, `awaitingRetry`, `closed`), чужая доска и «Закрыт» останавливают
автозапуск. Раньше второй `start` получал `TERMINAL_ALREADY_ACTIVE` /
`TERMINAL_AWAITING_RETRY`, а модалка показывала «Действие не выполнено».

`SILENT_ERRORS` в `LockPickingModal.js` содержит штатные коды сервера;
для `KEY_REQUIRED`, `TERMINAL_VIEW_ONLY`, `TERMINAL_CLOSED` и ожидания
решения Мастера показываются адресные подсказки. `SESSION_FORBIDDEN` /
`CHAR_NOT_PUBLISHED` один раз публикуют лист персонажа через
`pushSavedCharacterToBoundRoomIfAny` и повторяют действие.

### 2. Отмычки находятся в любом инвентаре

`server/lockPicking.js` (канон, тот же файл использует сервер комнат и
локальный резерв): `countBobbyPins` понимает словарь `items` с ключом
экземпляра, массив `equipment.items`, `inventory`/`bag`, поля `itemId`,
`catalogId`, `weaponId`, `code`, `id`, вложенные `item`/`snapshot`/`data`,
количество в `quantity`/`count`/`qty`/`amount` (в том числе строкой с
пробелами и запятой). Один экземпляр не удваивается. Добавлены алиасы
PER/LOCKPICK и поле `bag` в разборе снимка. Счётчик экспортирован для тестов.

Если отмычек действительно нет, доска уходит в `awaitingRetry` с подсказкой
`lock.noPinsHint` (парная RU/EN) вместо пустого окна и глухого отказа.

### 3. Локальный резерв для старого сервера комнат

`components/lootTrade/localLockGame.js` — по образцу
`localTerminalGame.js` (патч 498): тот же чистый движок
`server/lockPicking.js`, генерация доски, нажатия стрелок, поломки отмычек,
локальный `spentPins` и «Да/Нет» Мастера. Резерв включается автоматически,
когда у комнаты нет `capabilities.terminalHacking` и `terminalStates`, а
также если сервер ответил `UNKNOWN_TYPE` / `TERMINAL_NOT_ISSUED`. Видимого
переключателя «локальный режим» нет (правило 498). Секретная комбинация
не покидает клиентский снимок: в UI уходит `publicLockGameState`.

На старом сервере локальная победа не может открыть серверный замок точки —
Мастер снимает блокировку вручную, как и раньше. На обновлённом сервере
поведение не меняется: доска, оператор и журнал событий живут на сервере.

### 4. Окно локации и «Покинуть локацию»

- `visible={!terminalSelection}` у окна локации: пока открыта мини-игра,
  окно локации не выглядывает из-под затемнения и его кнопки не «залипают».
- `leaveLocation` помечает сессию закрытой **сразу**, до ответа сервера;
  сетевой запрос по-прежнему уходит, поэтому сессия Мастера активна для
  остальных игроков. Кнопка работает и на старом сервере без
  `session.playerClose`.
- Одиночная проверка, выданная как локация (старый резерв Мастера:
  `containerId` сессии совпадает с единственным узлом-замком/терминалом),
  теперь открывается сразу мини-игрой — без списка точек и без кнопки
  «Покинуть локацию», которая там не к месту.

## Регрессионные инварианты

- Защита сервера не ослаблена: лимиты сообщений, проверки роли и владельца,
  валидация снимков, целые положительные количества и атомарность переноса
  из 522 сохранены без изменений.
- Правила мини-игры 520: `N = 12 − PER + 2·D`, четыре стрелки, позиционное
  угадывание, одна отмычка в руке, спас-бросок Удачи, серые стрелки после
  поломки, «Да/Нет» Мастера, один взлом на трансляцию.
- Граф локаций 523, адресный взлом без каскада, граница видимости, общие
  ресурсы привязанных комнат и одна сессия со стеком вложенности — без
  изменений.
- Двупанельное окно склада, ключи только для чтения, парные RU/EN строки и
  правило «без видимого локального режима» сохранены.
