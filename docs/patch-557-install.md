## Как это выглядит

1. Панель «Общее хранилище» остаётся той же панелью с тем же заголовком.
2. На её верхней границе — две вкладки на всю ширину панели, по половине
   каждая: мешок «Вещи» и ключ «Ключи». Активная подсвечена золотым.
3. «Вещи» — привычный обмен: буфер «Отдаю на склад» и строки с «Забрать» /
   «Забрать всё». Буфер появляется только когда вещи уже отложены.
4. «Ключи» — список ключей и записок; нажатие на строку открывает текст, внизу
   подпись «Запись остаётся общей: забрать её нельзя».
5. На телефоне вкладки живут внутри панели склада: сначала выбираете панель
   («Предметы персонажа» / «Общее хранилище»), потом вкладку внутри склада.
6. У Мастера — те же две вкладки: состав склада и выдача ключей.

## Установка через консоль

```bash
git fetch --no-tags origin arena/a97ebb5a-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 557
```

После установки: `git add -A && git commit -m "Патч 557"`.
