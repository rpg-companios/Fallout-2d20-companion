# Трассировка приложения (debug-трасса)

Единый механизм логирования для диагностики «что происходит на каждом этапе».

## Принципы (ПРАВИЛО)

- По умолчанию трассировка **выключена**: ни одной записи, ни одного вызова
  console, ноль аллокаций. Прод и тесты работают в тишине.
- Включается **только вручную из консоли браузера** — пересборка не нужна.
- Точки трассировки живут в коде постоянно, но проходят через один гейт
  (`src/debug/falloutDebug.js`). Плоские `console.*` в коде запрещены —
  инвариант: `__tests__/debug/console-trace.test.js`.

## Как включить

1. Открыть приложение (web-превью), F12 → Console.
2. Вставить целиком `scripts/console-trace.js` → Enter (шаг можно пропустить и
   сразу вызвать `__fallout.on()`).

## Управление (`__fallout`)

| Команда | Действие |
|---|---|
| `__fallout.on()` | включить все категории |
| `__fallout.on(['equip','items'])` | только перечисленные категории |
| `__fallout.off()` | выключить (буфер не стирается) |
| `__fallout.status()` | `{ enabled, categories, buffered }` |
| `__fallout.mark('шаг 2')` | маркер-запись — разделитель этапов репро |
| `__fallout.dump('equip')` | JSON-строка буфера, фильтр по префиксу события; без аргумента — весь буфер |
| `__fallout.clear()` | очистить буфер |

Событие пишется и в консоль (`[FALLOUT_DEBUG] <event> <data>`), и в кольцевой
буфер `__FALLOUT_DEBUG_LOGS` (последние 1000 записей).

## Категории

Категория = префикс события до первой точки (`equip.armor:entry` → `equip`).

| Категория | Что трассирует |
|---|---|
| `character` | снапшот рендер-состояния персонажа |
| `weapon` | сборка списков оружия на экранах |
| `skill` | навыки: переключение, изменение значений |
| `equip` | надевание/снятие брони и одежды (все ворота решений) |
| `items` | стор предметов: добавление, стеки, выборки |
| `kits` | комплекты снаряжения: резолв и выдача |
| `consumable` | применение расходников: лечение, эффекты, зависимость |
| `store` | стор: атрибуты/навыки/эффекты не найдены, блокировки |
| `i18n` | локализация предметов (резолв chem и т.п.) |
| `catalog` | каталог экипировки: отсутствующие i18n-записи |
| `sync` | облачная синхронизация |
| `ctx` | контекст персонажа (deprecated-вызовы) |
| `trace` | служебные маркеры (`__fallout.mark`) |

## Репорт бага по трассе

```js
__fallout.clear();
__fallout.mark('начало репро');
// ...воспроизвести баг в UI...
__fallout.mark('конец репро');
copy(__fallout.dump());          // или dump('equip') — только категория
// вставить из буфера обмена в репорт
```

В буфер и консоль пишутся только события с момента `on()`; до включения —
ничего.
