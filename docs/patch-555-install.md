# Установка патча 555: ПК-режим карточек в окне комнаты

Патч подготовлен от состояния **версии 554**. Файл установки:
`patchs/555-pc-mode.patch`.

> **Слово владельца:** «Переключатель будет в окне просмотра комнаты.
> Делай 555». До этого патча ПК-режима не существовало: в настройках был только
> «Экран администратора» — это доступ к пространству Мастера, а не широкий
> показ карточек.

## Что меняется

В панели комнаты (там, где код комнаты, доставка команды и «Команда группе»)
появляется кнопка **«ПК-режим»**. Нажатие включает широкий показ карточек,
повторное — выключает. Выбор сохраняется: он записан как обычная настройка
движка `gmPcMode` (по умолчанию выключено) и переживает перезапуск приложения.

Режим включается **только нажатием**, никогда по ширине окна.

## Как проверить руками

1. Открыть пространство Мастера, зайти в папку-комнату (там, где виден код
   комнаты и «Команда группе»).
2. Нажать **«ПК-режим»** — кнопка подсвечивается, карточки становятся широкой
   колонкой, все разделы раскрыты, у перков видно пояснение эффекта.
3. Нажать ещё раз — карточки возвращаются к узкой ленте со спойлерами.
4. Перезапустить приложение: выбранный режим сохраняется.

## Установка через консоль

```bash
git fetch --no-tags origin arena/a97ebb5a-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 555
```

После установки: `git add -A && git commit -m "Патч 555"`.
