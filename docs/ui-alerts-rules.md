# Правила работы с уведомлениями (Alerts)

## Основное правило

**Все уведомления в приложении должны выводиться через `showRawAlert` из `components/alerts/alertService.js`.**

Не используйте:
- `Alert.alert()` из react-native (не работает в web-сборке)
- `window.alert()` / `window.confirm()` (не работает в нативной сборке)
- Прямой вызов модальных окон

## Почему

- **Кросс-платформенность**: `showRawAlert` работает и в web, и в нативной сборке
- **Единообразие**: все уведомления выглядят одинаково
- **Логирование**: уведомления проходят через единую точку, что упрощает отладку

## Исключения

Используйте `showAlert(alertId)` для уведомлений из каталога (`components/alerts/catalog.js`), когда:
- Уведомление заранее определено в каталоге
- Нужны локализованные тексты из i18n
- Нужно использовать стандартные кнопки (Да/Нет/Отмена)

## Примеры

### ❌ Плохо
```javascript
Alert.alert('Ошибка', 'Что-то пошло не так');
window.alert('Внимание!');
```

### ✅ Хорошо
```javascript
import { showRawAlert } from '../../components/alerts/alertService';

showRawAlert('Ошибка', 'Что-то пошло не так');

// Или для подтверждения
import { confirmAlert } from '../../components/alerts/alertService';
const confirmed = await confirmAlert('myAlertId');
```

## Дополнительно

- Для уведомлений с выбором (Да/Нет) используйте `confirmAlert(alertId)`
- Для уведомлений с несколькими вариантами используйте `showAlert(alertId)` с `kind: 'choice'`
- Все уведомления из каталога должны иметь корректные переводы в i18n файлах
