# Установка патча 546: замок локации — преграда входа

Патч подготовлен от состояния **версии 545**. Файл установки:
`patchs/546-location-lock-barrier.patch`.

> Баг владельца: «Подвал доктора» помечен «заблокировано: Запертый люк»,
> «Тапхаус» — «заблокировано: Запертая дверь», но игрок свободно входит,
> выходит и лутает содержимое (включая торговца «Безумный доктор») без взлома.

## Границы

- Замок по-прежнему не самостоятельная точка игрока: он преграда цели.
- Взлом адресный: открытие «Запертого люка» открывает Подвал доктора, но не
  Тапхаус; каскада по детям и воротам нет.
- Закон снимка 529 сохранён: сервер не правит лист игрока.
- Порядок мест 545, маркер пространственного узла 544, gate-first 542 и
  перекрытие проходов 543 не менялись.
- Для полной серверной защиты обновите лёгкий сервер комнат (`server/` + `ws`)
  через `deploy-netangels.sh`; клиентская страховка закрывает окно игрока и на
  старом сервере, но прямой WS-запрос к старому серверу он заменить не может.

## Установка через консоль

```bash
git fetch --no-tags origin arena/f90c80d8-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 546
```

## Проверки

- `npm run typecheck`: успешно.
- `npm test`: зелёные, кроме восьми заранее известных падений
  `__tests__/room/terminal-hacking-balance-496.test.js` — они падают теми же
  ошибками и на чистом дереве 545, патч 546 их не трогает.
- `npm run build`: веб-сборка Expo проходит.

## Откат

`git apply -R patchs/546-location-lock-barrier.patch` вернёт дерево,
словари и версию к состоянию 545.
