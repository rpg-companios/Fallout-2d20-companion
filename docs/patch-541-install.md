## Установка через консоль

Из корня репозитория приложения: сначала заменить `apply-patch.sh` свежей
версией из ветки доставки, затем поставить патч 541.

```bash
git fetch --no-tags origin arena/aa289f1c-fallout-2d20-companion
git show FETCH_HEAD:apply-patch.sh > apply-patch.sh
chmod +x apply-patch.sh
./apply-patch.sh 541
```

Старый локальный `apply-patch.sh` смотрел на предыдущую ветку и не видел
патч 541, поэтому его нужно обновить до запуска. После установки скрипт
берёт патчи из `arena/aa289f1c-fallout-2d20-companion`.
