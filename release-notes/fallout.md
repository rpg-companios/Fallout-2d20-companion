# Fallout 2d20 — заметки о релизах

Публикация берёт **верхнюю** секцию этого файла и кладёт её в GitHub Release.
Номер секции должен совпадать с версией, которую выпускает
`./scripts/publish-setting.sh`; перед выпуском добавьте новую секцию сверху.

```
## 1.0.2 — Короткий заголовок
Что изменилось для игрока: одна-две строки.
```

## 1.0.0 — Первый пакет

Сеттинг Fallout 2d20 для движка Positronium ставится отдельным файлом `.trpg`:
по ссылке на релиз или выбранным файлом в настройках сеттинга. Внутри —
правила Fallout 2d20, экраны персонажа, инвентаря и снаряжения, перки,
происхождения, крафт, выживание и локализация на русский и английский.

Движок поставляется без сеттинга: пока пакет не установлен, экраны Fallout
не появляются.
