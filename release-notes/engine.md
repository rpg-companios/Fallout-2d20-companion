# Positronium — заметки о релизах движка

Релиз берёт **верхнюю** секцию этого файла и кладёт её в GitHub Release.
Номер секции должен совпадать с версией из `app.json` — иначе
`./scripts/release.sh` останавливается до сборки. Перед выпуском добавьте
новую секцию сверху.

```
## 1.0.2 — Короткий заголовок
Что изменилось для игрока: одна-две строки.
```

## 1.0.1 — Иконка и проверка обновлений

Приложение снова с иконкой: лаунчер Android берёт логотип Positronium, а не
заглушку из шаблона. В приложении появилось окно «Что нового» и проверка
обновлений, а сам APK — по постоянной ссылке
`releases/latest/download/positronium.apk`.

## 1.0.0 — Первый выпуск движка

Приложение Positronium без встроенного сеттинга. Установка правил — отдельным
пакетом `.trpg`: по ссылке на репозиторий сеттинга или выбранным файлом в
настройках; дальше пакет обновляется сам, проверяя `release.json` своего
репозитория.

Движок объявляет набор модулей `engine:<id>`, которые отдаёт пакету, — поэтому
сеттинг можно собрать и обновить, не пересобирая приложение.
