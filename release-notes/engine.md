# Positronium — заметки о релизах движка

Публикация берёт **верхнюю** секцию этого файла и кладёт её в GitHub Release.
Номер секции должен совпадать с версией, которую выпускает
`./scripts/publish-engine.sh --release` (она берётся из `app.json`); перед
выпуском добавьте новую секцию сверху.

```
## 1.0.1 — Короткий заголовок
Что изменилось для игрока: одна-две строки.
```

## 1.0.0 — Первый выпуск движка

Приложение Positronium без встроенного сеттинга. Установка правил — отдельным
пакетом `.trpg`: по ссылке на репозиторий сеттинга или выбранным файлом в
настройках; дальше пакет обновляется сам, проверяя `release.json` своего
репозитория.

Движок объявляет набор модулей `engine:<id>`, которые отдаёт пакету, — поэтому
сеттинг можно собрать и обновить, не пересобирая приложение.
